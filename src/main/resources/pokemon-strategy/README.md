# 物种培养参考 v1

`overview-v1.json` 是默认本地攻略资料集，schemaVersion 3，共14篇项目原创笔记：原12篇正文和来源登记保留，新增杰尼龟、雪妖女两篇条件培养说明。`sources-v1.json` 保存两种成员的公开字段投影及原抓取时间/摘要，不含账号数据、模型配置或完整上游正文。

策略说明以已捕获的种族值与项目输入边界为依据，由项目编写，不是PokéAPI发布的战术推荐。示例分配只供明确条件下比较；未核验的机制、完整配招、当前热门阵容和赛事资格不作事实结论，独立人工审核仍待完成。

`applicability.subjects` 登记明确适用的中文物种名/英文slug；`topics` 可用 `training / team / resource / reference / damage / project`。通用文档的subjects为空。检索先检查语言/游戏/赛制/规则、日期与声明范围，再在有词法匹配的候选中优先同物种文档，组内仍按BM25排序。没有物种名称时不猜测指代；未登记物种不回退到其他物种笔记。标签和关键词规则不是语义理解或机制正确性证明。

新库保留同一原文定位、摘要校验与SQLite事务导入。元数据改变会改变文档版本与片段身份；原12篇冻结文件和旧评测不改。

明确单只培养请求已取得对应事实、但尚无对应笔记时，在原工具网关内最多补一次原问题首行检索，避免模型遗漏物种词或反复读取不可用资源。标记为`PROGRAM_SPECIES_SOURCE`；已经取得对应笔记、无已核验事实、计算/队伍门禁激活、版本或工具能力缺失时不触发。用户明确要求查询机制时仍须先实际尝试资源读取，失败就保留缺失说明。不为找不到的物种造笔记，也不把该查询当成模型自主选择。

需要复现旧12篇时显式设置：

```powershell
$env:VIO_LOCAL_GUIDES_LOCATION='classpath:pokemon-guides/expanded-v1.json'
$env:VIO_LOCAL_GUIDES_PATH="$PWD/.local-data/guides-expanded-replay.sqlite"
```

清除覆盖变量并重启后使用新版默认资料。不要让两个资料版本共用同一索引文件运行；旧实例会拒绝读取被另一实例替换的索引。历史片段链接不承诺跨资料版本继续有效，原文仍可从旧来源/评测记录核对。

来源生成工具：`node tools/campus/build-species-guides.mjs PUBLIC_BUNDLE NEW_DIRECTORY`，拒绝覆盖已有版本。它验证公开缓存包与Pokemon/species配对后生成字段投影和原创笔记；打包时间不代表重新联网取数。后续扩充须建立新的来源版本、同步标注、验证，再切换默认配置，不在原冻结文件中改标签追求成绩。
