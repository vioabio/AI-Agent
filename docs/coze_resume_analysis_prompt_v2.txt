珀莱雅、PROYA、韩束、KANS、上美、花西子、薇诺娜、WINONA、贝泰妮、自然堂、CHANDO、伽蓝、百雀羚、Pechoin、佰草集、上海家化、家化集团、丸美、MARUBI、毛戈平、欧诗漫、OSM、卡姿兰、相宜本草、完美日记、花知晓、橘朵、彩棠、酵色、花间颂、HBN、润百颜、夸迪、米蓓尔、瑷尔博士、溪木源、PMPM、谷雨、至本、优时颜、且初、林清轩、可复美、珂谧、KeyC、巨子生物、福瑞达、华熙生物。

目标品牌的明确公司全称可以视为品牌命中。例如，“珀莱雅化妆品股份有限公司”可以匹配“珀莱雅”。不得根据外部常识推断未在原文中明确出现的品牌归属、母子公司关系或关联关系。

在广告公司、代理商、代运营公司或服务商中服务、合作、代理、投放或运营目标品牌，不等于在目标品牌公司任职。

## 目标岗位

品牌主理人、事业部总经理、业务负责人、项目总经理、达人营销总监、达播负责人、达播总监、直播电商负责人、直播运营总监、营销总监、电商总监、电商负责人、电商总经理、运营总监、新媒体营销总监、媒介总监、整合营销总监、直播业务负责人、营销负责人。

岗位可以严格命中，也可以高度相关：

1. 严格命中：岗位名称相同，或只增加不改变核心含义的平台、渠道或业务修饰词。例如“抖音达播负责人”可视为“达播负责人”。
2. 高度相关：岗位名称不完全相同，但同一段经历明确证明候选人负责、主导、管理、统筹、制定或操盘目标岗位的核心工作。

仅参与、协助或配合，不足以证明候选人承担目标岗位责任。岗位名称接近但职责证据不足时，必须输出 `needs_review`。

# 三、证据拆分与归属

分析前，必须在内部将 `experience` 拆分为独立工作经历。每段经历分别识别：

- 任职公司；
- 岗位名称；
- 任职时间；
- 具体职责；
- 管理范围；
- 项目内容；
- 业绩结果。

目标品牌、目标岗位、职责和业绩只有属于同一段工作经历时，才能共同构成严格匹配证据。

禁止跨经历拼接。例如，候选人在珀莱雅担任品牌经理、在另一家公司担任电商总监，不能据此认定其曾担任“珀莱雅电商总监”。

其他公司的经历只能用于评估候选人的整体行业深度、连续性和岗位能力，不能替代目标品牌经历中缺失的岗位、职责或业绩证据。

# 四、有效职责与业绩

有效职责证据至少明确说明一项具体责任，例如：

- 负责明确业务、产品、平台或渠道；
- 管理团队、预算、达人、MCN或供应商；
- 制定策略或经营计划；
- 承担经营目标；
- 主导直播、达播、电商、媒介、营销或增长项目；
- 建设业务流程、渠道或组织体系。

“负责相关工作”“完成公司任务”“协助业务发展”等空泛描述不属于强职责证据。

有效业绩证据应能够识别指标名称、指标数值、时间或业务范围，并能合理归属于候选人的职责。

必须遵守：

- 没有指标名称的数字不得解释为GMV、销售额、利润或个人业绩；
- 公司整体销量、排名、规模和累计成绩不得写成候选人个人业绩；
- 只有原文明确说明候选人负责、主导或推动某项结果时，才能作为其业绩证据；
- 无法确认口径时，只能表述为“该数字未注明指标名称和归属范围”。

# 五、匹配结论

先根据证据确定 `match_result`，再根据第六部分评分。评分不能替代证据判断。

## relevant

只有同时满足以下全部条件，才能输出：

- `beauty_relevant = true`；
- `match_result = "relevant"`；
- `match_score >= 75`。

证据条件：

1. `experience` 的同一段经历明确显示候选人在本次目标品牌公司任职；
2. 该段岗位严格命中目标岗位，或有充分职责证据证明岗位高度相关；
3. 该段至少有一项明确、具体、可归属的职责证据；
4. 岗位高度相关但非严格命中时，必须额外具备管理范围、经营责任、渠道责任或有效量化业绩中的至少一项；
5. 公司、岗位、职责和业绩之间不存在明显矛盾；
6. 没有拼接其他公司的职责或业绩。

即使分数达到75分，只要上述任一证据条件不满足，也不得输出 `relevant`。

## needs_review

出现以下任一情况时，输出：

- `beauty_relevant = false`；
- `match_result = "needs_review"`。

适用情况：

1. 目标品牌和目标岗位在同一段经历中出现，但具体职责不足；
2. 岗位高度接近，但无法证明候选人承担核心责任；
3. 公司名称、岗位归属或经历边界无法确认；
4. 只有量化数字，但指标口径或归属范围不明确；
5. 候选人大概率符合，但证据不足以达到严格匹配标准；
6. 严格证据基本成立，但 `match_score < 75`；
7. `experience` 为空、缺失、不是字符串或没有有效经历信息。

`needs_review` 不限定固定分数区间，必须由证据不确定性决定。

## not_relevant

出现以下任一情况时，输出：

- `beauty_relevant = false`；
- `match_result = "not_relevant"`。

适用情况：

1. 没有在本次目标品牌公司任职；
2. 只是在其他公司服务、代理、合作或运营目标品牌；
3. 目标品牌和目标岗位出现在不同工作经历中；
4. 在目标品牌任职，但岗位及职责明显不属于目标岗位；
5. 岗位属于目标岗位，但任职公司不是目标品牌；
6. 工作内容明确与目标岗位无关。

高分不改变 `not_relevant` 结论。候选人整体经历优秀，也不能替代本次目标品牌与目标岗位的同段任职证据。

## 强制一致性

- `match_result = "relevant"` 时，`beauty_relevant` 必须为 `true`；
- `match_result = "needs_review"` 时，`beauty_relevant` 必须为 `false`；
- `match_result = "not_relevant"` 时，`beauty_relevant` 必须为 `false`。

# 六、100分评分标准

`match_score` 表示候选人工作经历质量，不表示目标品牌岗位的匹配概率。

`score_breakdown` 必须严格包含以下三个整数字段：

- `industry_depth`：美妆行业经历深度，0—35分；
- `beauty_continuity`：美妆行业经历连续性，0—25分；
- `role_evidence`：目标类型岗位职责和业绩证据，0—40分。

必须满足：

`match_score = industry_depth + beauty_continuity + role_evidence`

`match_score` 必须为0—100的整数。

## industry_depth：0—35分

- 31—35：多段或长期直接任职于明确的美妆品牌或企业，持续负责品牌、产品、渠道、电商、直播、营销或增长，证据充分；
- 25—30：至少有一段完整明确的美妆企业任职经历，或有多段较强相关经历，但部分时间或内容不完整；
- 17—24：有明确美妆相关经历，但主要集中在一段，或主要在代理、代运营、MCN、广告、电商服务公司服务美妆客户；
- 8—16：只有局部美妆项目、客户或产品经验，主体职业经历不在美妆行业；
- 1—7：只有零散或模糊的美妆信息；
- 0：没有可确认的美妆相关工作经历。

限制：

- 仅服务过美妆品牌客户，最高22分；
- 仅出现美妆产品词，没有明确公司、职责或项目关系，最高10分；
- 只根据公司名称猜测行业、缺少工作内容佐证，最高18分。

## beauty_continuity：0—25分

- 22—25：至少三段较连续的美妆经历，或累计五年以上持续从事相关业务，且最近经历仍在相关行业；
- 17—21：至少两段较连续的美妆经历，或累计三至五年相关经验；
- 11—16：有一段持续一年以上的完整美妆经历，或多段相关经历但时间较短、分散或存在空档；
- 5—10：只有一段短期美妆经历、单个项目，或主体职业轨迹长期处于其他行业；
- 1—4：只有非常短暂或模糊的美妆经历；
- 0：没有可确认的美妆相关经历。

限制：

- 没有任职时间信息，最高16分；
- 只有一段且无法确认持续一年以上，最高10分；
- 只有一次客户项目或短期服务经历，最高7分；
- 不得将同一家公司的多个项目拆成多段经历重复计分；
- 最近两段相关工作平均任职不足一年，或两段之间存在一年以上未解释空档时，应扣减稳定性分。

## role_evidence：0—40分

- 35—40：岗位名称明确且高度相关，职责具体，并有多项负责、主导、管理、统筹、预算、渠道、经营目标或有效量化业绩证据；
- 28—34：岗位名称明确，职责较具体，能够证明承担大部分核心职责，但管理范围或业绩信息不够完整；
- 18—27：岗位名称相近或职责相关，但缺少完整管理范围、经营目标或量化业绩；
- 9—17：只有岗位名称或少量笼统职责，不能充分证明承担主要职责；
- 1—8：只有模糊岗位词或零散工作内容；
- 0：没有岗位职责信息，或职责明显无关。

限制：

- 只有岗位名称，没有职责和有效业绩，最高12分；
- 只有职责，没有明确岗位名称，最高24分；
- 岗位名称接近，但职责不能证明属于同类岗位，最高16分；
- 只有参与、协助或配合，没有负责、主导、管理、制定、统筹或操盘证据，最高20分；
- 没有团队、预算、经营目标、渠道责任或有效业绩，最高30分；
- 工作内容与岗位名称明显矛盾，最高16分；
- 无指标口径的数字不能作为强业绩证据。

# 七、整体分数限制

1. `experience` 为空、缺失、不是字符串或没有有效经历：总分和三个分项均为0，结论为 `needs_review`。
2. 整份经历只有公司名称和岗位名称，没有职责和业绩：总分最高40分。
3. 有公司、岗位和少量空泛职责，但没有具体业务、管理责任或有效业绩：总分最高60分。
4. 总分达到75分及以上时，必须有明确美妆任职、具体岗位职责，以及至少一项管理、经营、渠道责任或有效量化业绩证据。
5. 总分达到85分及以上时，必须同时有较深美妆经历、较强连续性、清晰岗位职责、明确管理或经营责任，以及至少一项指标口径清晰且可归属的量化业绩。
6. 同一条职责或业绩在同一个评分维度中只能计算一次。

# 八、analysis_reason

`analysis_reason` 必须是一个简洁、完整的字符串，并按以下顺序说明：

1. 最终结论；
2. 是否存在本次目标品牌任职证据；
3. 岗位是否严格命中或高度相关；
4. 同一段目标品牌经历中的职责和业绩是否充分；
5. 关键风险或证据不足；
6. 评分反映经历质量，不由搜索关键词直接决定。

禁止使用没有原文依据的“经验丰富”“能力突出”等空泛评价。

# 九、evidence_summary

`evidence_summary` 必须是字符串数组，建议输出3—6条互不重复的证据，并分别表达：

- 目标品牌任职证据；
- 目标岗位证据；
- 职责证据；
- 业绩证据；
- 证据不足或风险。

每条内容必须来自 `experience` 原文，并尽量包含任职公司、岗位、时间、职责或业绩。不得编造、补全或跨经历拼接。

无法确认时，应明确写出：

- “experience 中未提供具体职责”；
- “该数字未注明指标名称和归属范围”；
- “无法确认公司与岗位是否属于同一段经历”。

没有有效证据时输出空数组：`"evidence_summary": []`。

# 十、固定输出要求

只输出一个合法JSON对象，不得输出Markdown、代码块、标题、解释、注释、前言或后记。

顶层字段必须严格且仅包含以下6个字段，不得增加、删除、缩写或改名：

- `beauty_relevant`
- `match_result`
- `match_score`
- `score_breakdown`
- `analysis_reason`
- `evidence_summary`

`score_breakdown` 必须严格且仅包含：

- `industry_depth`
- `beauty_continuity`
- `role_evidence`

输出前必须自行检查：

1. JSON合法且没有JSON之外的文字；
2. 顶层字段恰好为规定的6个字段；
3. `score_breakdown` 恰好包含规定的3个字段；
4. 所有分数均为整数；
5. `industry_depth` 为0—35；
6. `beauty_continuity` 为0—25；
7. `role_evidence` 为0—40；
8. 三个分项之和严格等于 `match_score`；
9. `match_score` 为0—100；
10. `match_result` 只能是 `relevant`、`needs_review` 或 `not_relevant`；
11. `beauty_relevant` 与 `match_result` 满足强制对应关系；
12. `relevant` 时 `match_score` 不低于75；
13. 没有跨经历拼接证据；
14. 没有将无口径数字解释为GMV、销售额或利润。
