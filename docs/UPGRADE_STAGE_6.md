# 第 6 阶段：只读工具与有限编排（离线初版）

日期：2026-11-05。主计划见 [升级方案 V2](AI_APPLICATION_UPGRADE_PLAN_V2.md)。

已实现**四个绑定当前快照的只读工具、必跑配置检查、有限循环和合成控制流对照**。当前仅使用脚本 provider，不调用 SDK、HTTP 服务或真实模型；没有上线 Agent、MCP 服务或生产工具路径。第 6 阶段整体保持开发中，真实工具选择质量和生产预算接入未验收。

## 1. 交付内容

| 文件 | 职责 |
| --- | --- |
| `bounded_tools/registry.py` | 四工具白名单、严格参数、固定候选人/岗位/快照、原文与最终引用校验 |
| `bounded_tools/intervals.py` | 仅从明确职责区间计算自述月份覆盖，合并重叠，保留未知项和原文位置 |
| `bounded_tools/runner.py` | 准备事实 → 模型回合 → 工具 → 最终校验；限制轮数、次数、输出、预算和时间 |
| `analysis_intake.py` | 提取共用 `evaluate_collection_rules`，供采集与工具运行强制执行；intake 版本增加自身源文件摘要 |
| `eval/fixtures/tool_provider.py` | 固定脚本回复，不是语言模型，不负责证明真实模型行为 |
| `eval/bounded_tools_demo.py` | 20 个合成场景、无工具/有工具的流程对照、无正文事件日志 |

四个工具：

| 名称 | 模型可提供的参数 | 服务端固定的边界 |
| --- | --- | --- |
| `search_resume_evidence` | 合法 dimension_id、query（可为 null） | 当前快照、当前岗位查询计划，最多 3 个词法命中 |
| `read_evidence_chunk` | 当前快照中的 chunk_id | 只在当前分块映射查找；不能指定候选人、快照、路径或 URL |
| `get_job_requirements` | 空对象 | 固定岗位版本、评分规则与配置检查状态，无任意岗位切换 |
| `calculate_experience_intervals` | python_backend/java_backend/ai_deployment 三选一 | 当前原文、明确职责标签、服务端 as_of_month；不能提交任意日期来抬高年限 |

参数使用 Pydantic strict + extra=forbid，并拒绝重复 JSON 属性及 NaN；未知工具/非法参数不被执行。函数声明、call ID 与工具回复的关联形式核对了本机 SDK 类型及 [OpenAI Docs 函数调用说明](https://developers.openai.com/api/docs/guides/function-calling)。声明的 strict schema 满足字段全部 required、对象禁止额外字段；可选查询采用必填 nullable 字段。本轮未通过 SDK 发出这些工具声明，不能据此宣称所有 provider 支持该 schema。

## 2. 规则、来源和引用

配置中的统招本科/意向城市检查由共用函数先执行，模型不能通过不调用工具来跳过。未知或不满足检查时，不启动模型回合，不产生匹配评分；实验运行状态进入复核。这个共享检查不完整覆盖年龄、冷却、现场身份及所有岗位年限规则；原手机链路的前置规则仍须保留，也不证明学历本身真实。

服务端构造 `BoundTools` 时验证快照身份、完整正文与采集记录一致，并固定岗位、事实和 as_of_month；模型参数没有授权范围选择权。最大输入正文为 50000 码点。该库不是公开授权 API，未来接入仍须先走现有 HR/任务权限，再由服务端提供上下文。

检索及片段返回 exact-codepoints-v1 的原文范围，原文内容始终作为数据。空检索不表示没有经历，匹配位置也不证明语义支持。参数不能访问 shell、SQL、任意文件、网络、其他候选人或历史分析。

最终结果保留现有六字段业务契约，引用位置单独返回，不修改旧 schema/数据库引用契约。实验要求至少一条证据，每条 evidence_summary 都有唯一 summary_index、逐字 quote 及当前快照内有效半开范围；逐字摘要与 quote 必须一致。越界、错误 quote 或额外 snapshot_id 等会终止并转复核，不能通过修复或全文回退绕过。原文引用正确仍不等于评分或推理正确。

## 3. 月份工具的适用范围

仅处理以下明确自述格式，例如：

```text
职责区间：2021.01-2023.12；职责：负责Python后端开发。
职责区间：2023.01-2024.06；职责：独立负责Python后端开发。
```

重叠去重后覆盖 **42 个日历月份**，完整日历月的保守范围为 **38–42**；这不是“已验证 3.5 年 Python 工作经验”。输出保留逐字来源及未知区间，verified_employment_years 始终为 null。

公司总任期不计入技术职责区间。“仅参与”“未负责”、模糊职责、错误日期和未来日期保留 unknown；既有明确区间又有未知项时返回 partial。至今按绑定 as_of_month 截止，as_of 变化进入版本摘要。当前只识别少量明确标签/职责词，不对普通自由履历做无依据推断。

合并月份范围使用 `year*12+month-1` 的内部月份索引，右端不含；主要提供给程序使用，同时保留原始日期文本。日精度缺失，所以不会将首尾月份都声称为完整任职月，也不直接输出真实就业年限。

## 4. 有限循环与回退

默认最多 **3 个模型回合（包括最终结果）/ 6 次工具执行 / 1 次结构修复 / 15 秒逻辑时限**。另有模型输入/回复大小、单工具输出大小、请求/token/费用上限。多工具帧先整批校验再执行，重复 call ID 被拒绝；超出工具数上限不执行额外工具。

- provider 明确声明 tools unsupported 时可走全文；运行中只有专门的 `ToolsUnsupported` 能触发一次全文回退。未知能力或普通 provider 错误不能被当作“不支持工具”。
- 回退、修复和后续回合使用调用方提供的同一个 RequestBudget、同一模型回合上限；不会重新分配预算。费用上限存在而价格未知时，不派发回合。
- 评分/结构不合约可在剩余预算内修复一次；伪造引用、越权、非法工具/参数、工具异常、超限或超时直接复核，不通过其他路径继续。
- 调用前后都检查时限。预留后到派发前已到期时不会启动 provider，报告区分预留次数和实际脚本回合；预留保守保留，未结算项清空。

这里复用的是第 2 阶段的**单进程串行 RequestBudget**：已知 usage 按报告结算，未知分项保留预留；与第 5 阶段数据库保守账本不是同一个实现。尚未接入队列持久化/多 Worker 共享额度，不能把整个循环直接塞进“每租约一次 SDK 请求”的回调中。接入时应让每个 SDK 回合单独预留/记录，并保存编排状态。

输入单位与费率均为合成约定，UTF-8 大小不是真实 tokenizer。时间限制也不能杀死已运行的 Python 回调/网络请求，只能阻止后续调用及结果发布。真实 SDK 超时与取消仍需独立适配。

## 5. 本地实跑

```powershell
.\.venv\Scripts\python.exe -m eval.bounded_tools_demo
```

CLI 没有密钥、URL 或真实数据参数，不读取 `.env`，不初始化模型 SDK/设备/数据库。结果位于 `artifacts/eval/tools/tools-20261105T054530Z-025889b3/`，包含 `report.json` 与 `events.jsonl`。仅输出版本/响应/参数/结果摘要、状态、预算和调用计数；不复制原文、工具输出、provider 错误或最终评分 payload。

| 项目 | 实际结果 |
| --- | --- |
| 合成场景 | 20 |
| 流程成功 / 转复核 | 6 / 14 |
| 实际脚本回合 / 预留回合 | 23 / 23 |
| 工具执行 | 11 |
