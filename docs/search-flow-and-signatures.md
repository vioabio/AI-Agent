# 搜索闭环与页面签名清单

## 当前固定业务流程

本项目后续执行流程固定为：

```text
品牌关键词 + 岗位关键词
→ 进入搜索入口
→ 设置或确认筛选条件
→ 浏览结果列表
→ 对结果做初步筛选
→ 进入候选人详情页做详细筛选
→ 符合则点击沟通
→ 发送或准备发送
→ 退出并返回结果列表
→ 当前组合处理完成后清空条件
→ 进入下一个关键词组合
```

说明：

- 搜索任务必须严格使用冻结的 `53` 个品牌关键词与 `12` 个岗位关键词
- 不允许自动扩词、改写词、补同义词
- 结果列表只做“浏览 + 初筛”，严格判断必须尽量进入详情页
- 点击沟通后必须能够回退到结果列表或明确结束当前任务

## 每类页面至少需要的签名

### 搜索入口页

至少两类特征：

- 顶部搜索输入区域
- 历史记录或按职位搜索模块

### 搜索条件页

至少两类特征：

- 品牌/公司条件控件
- 岗位/职位条件控件
- 当前或历史任职范围控件
- 搜索提交按钮

### 结果列表页

至少两类特征：

- 顶部搜索/回退搜索框
- 排序/城市/经验/学历/更多 或 筛选按钮
- 至少一个候选人卡片 或 空结果文案

### 候选人详情页

至少两类特征：

- 候选人基本信息区
- 工作经历模块
- 沟通按钮区

### 沟通页 / 聊天页

至少两类特征：

- 输入框
- 发送按钮
- 历史消息气泡或沟通状态

### 异常页

至少两类特征：

- 关键错误文案
- 明确动作按钮，例如登录、重试、验证、升级

## 返回路径约束

### 从结果列表进入候选人详情

返回目标：

- 必须回到同一结果列表
- 不能跳回推荐首页
- 不能跳到职位页

验证点：

- 搜索关键词仍然存在
- 列表仍属于当前任务上下文

### 从详情页进入沟通页

返回目标：

- 沟通完成后回到详情页或结果列表
- 必须能确认本次候选人处理已结束

验证点：

- 当前候选人指纹未变化
- 沟通状态有记录

### 当前关键词组合结束

返回目标：

- 回到搜索入口或搜索条件页
- 清除上一个组合的品牌与岗位条件

验证点：

- 新组合输入前，旧条件不残留

## 当前已知风险

- 猎聘多个页面复用同一个 `.HomeActivity`，不能依赖 Activity 判断页面
- `uiautomator2` 在该设备上偶发残留 `UiAutomation` 会话，连接层必须自动清理重试
- 部分搜索相关页面会唤起输入法，因此页面签名必须兼容键盘弹出场景
