# 飞书招聘日报模板规范

## 发送方式

- Windows 计划任务每天 10:00 检查最近一个“已完成且未播报”的双岗位搜索批次。
- 搜索尚未形成完整批次时返回可重试状态，每 15 分钟重试一次，最多 48 次。
- 新一轮搜索已经开始时，上一轮完整且未播报的批次仍可独立播报，不等待新一轮结束。
- 正式发送成功后同时登记数据库发送记录与批次播报状态，避免同一批次重复发送。
- 测试群发送和 `--dry-run` 不更新正式批次播报状态。

## 日期口径

- 标题日期显示日报发送当天。
- 正式日报默认读取最近一个正常完成的双岗位搜索批次，不按自然日取数。
- 批次起点为达人营销岗位第一次开始搜索的上海本地时间，批次终点为财务共享与管理经理岗位正常结束的上海本地时间。
- 中途暂停、进程重启和断点续跑沿用原批次起点，不能拆成新批次。
- 只有第二个岗位正常完成后批次才可用于日报；未完成批次不得播报。
- 数据库 `created_at` 按 Asia/Shanghai 本地时间直接比较，不做减 8 小时处理；仅UTC格式日志在统计时换算时区。
- 正文不展示“数据日期”字段。
- 进展表第一列标题使用“今日”，表示本次日报播报批次。

## 招聘进展明细

- 达人营销总监与财务共享与管理经理分别使用独立区块展示，不合并统计。
- 每个岗位区块均包含独立的“今日 / 累计”指标表和本岗位下一步建议。
- 简历卡片浏览人次：统计播报批次的全部实际列表浏览量。
- 岗位匹配（今日）：只统计 AI 评分大于等于 90 且结论为 `relevant` 的候选人。
- 待人工复核（今日）：只统计 AI 评分大于等于 90 且结论为 `needs_review` 的候选人。
- 已打招呼（今日）：只统计真实发送成功、数据库状态为 `sent` 的候选人；`immediate_job_confirmed` 不计入。
- 累计：统计全部历史有效结果；岗位匹配与待复核不受 90 分门槛限制，已打招呼仍只统计 `sent`。

## 候选人明细与 PDF

- 仅展示 AI 评分大于等于 90 的候选人。
- 候选人 PDF 按招聘岗位分别生成，达人营销总监与财务共享与管理经理不再合并到同一文件。
- 某岗位没有 90 分以上候选人时，不生成空白 PDF，日报中注明“暂无 90 分以上候选人”。
- 有合法猎聘正式分享链接时，PDF显示可点击的“查看猎聘原始简历”。
- 没有合法链接时不显示空链接按钮。
- 不在日志或飞书正文暴露分享链接中的敏感参数。

## 下一步建议

- 下一步建议放在对应岗位指标表下方，两个岗位始终各有建议。
- 有 90 分以上明确匹配候选人时，建议优先推进沟通。
- 有 90 分以上待复核候选人时，建议完成人工判断并确认是否进入沟通名单。
- 没有 90 分以上候选人时，建议扩大搜索范围或调整搜索词与筛选条件。
- 低于 90 分的候选人不作为推荐对象写入建议。
