# 第 2 阶段：工具与合成验证交付记录

日期：2026-11-05。用户明确选择“先只完成工具与合成样本验证”，因此本次只验收离线工具，不进行人工真实标注、真实模型调用或生产接入。

## 已实现

| 能力 | 交付 |
| --- | --- |
| 回放评测 | 六字段岗位契约校验；失败、缺失、版本冲突保留分母并转复核 |
| 合成场景 | 确定性生成 42 条样本：dev 30 / test 12，覆盖正常、无效输出、重试、限流、超时、认证拒绝与未知 usage |
| 请求预算 | 调用前预留、调用后结算，覆盖重试；请求/token/费用上限，未知价格/usage、重复结算、超额与币种边界 |
| 调用事件 | 每次模拟尝试的 trace、run、sample、attempt、版本、usage、错误分类、费用与延迟，日志不含正文或原始错误 |
| 版本绑定 | provider/model、采样参数、岗位/prompt、契约/规则、检索/工具版本，绑定简历与数据集 hash |
| 缓存工具 | 输入/版本变动生成不同键，配置字段顺序不影响键；未切换现有生产缓存 |
| 证据工具 | 标注范围合法性、召回并集覆盖、引用原文一致性；语义支持率需人工，不伪造 |
| 配对统计 | 校验同集与身份分组，重算汇总；候选人分组 bootstrap 差值区间，零分母和小组数明确处理 |

完整操作命令见 [eval/README.md](../eval/README.md)。新增工具使用 Python 标准库与项目现有依赖，不要求安装新向量库、队列或模型服务。
