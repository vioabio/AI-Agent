# 一、任务目标

请严格且仅基于 `resume_record.experience`，判断候选人是否适合达人营销、达人运营、KOL商务、直播电商、内容营销或相关负责人岗位。

`resume_record.search_keyword` 只用于识别本次搜索的目标品牌和目标岗位。搜索关键词本身不是任职、职责或业绩证据，不得因此直接判定匹配或增加分数。

不得根据候选人姓名、来源平台、分析状态或外部知识补全简历中不存在的信息。

学历硬性要求由手机端教育卡片的独立徽标核验：只有输入明确出现“统招本科条件：满足”时，才可以输出 `relevant`。出现“统招本科条件：不满足”时必须输出 `not_relevant`；出现“统招本科条件：待确认”或没有该字段时必须输出 `needs_review`。不得仅根据“本科”、学校名称、985、211或搜索关键词推断为统招。

# 二、目标岗位

目标岗位共15个：

达人营销总监、媒介总监、直播电商负责人、达人运营总监、达人运营负责人、KOL商务BD、内容营销总监、新媒体营销总监、电商总经理、整合营销总监、直播负责人、抖音负责人、直播推广负责人、BD负责人、BD总监。

其中“媒介总监”“电商总经理”“BD负责人”“BD总监”等宽泛岗位，只有在同一段经历中存在明确的达人、KOL、KOS、MCN、直播、内容商务或达人分销职责时，才能视为目标岗位相关。

岗位名称可以严格命中，也可以高度相关。高度相关必须有具体职责证明候选人承担负责、主导、管理、统筹、制定、操盘或经营责任。仅参与、协助或配合不属于负责人级证据。

# 三、达人营销能力证据词

以下词语只用于识别职责和业绩证据，不能仅凭词语出现直接判定匹配。

## 1. 达人矩阵与资源

KOL矩阵、KOL资源、头部达人、腰部达人、垂类达人、跨界达人、达人孵化体系、达人资源库、达人分层管理。

## 2. 直播电商与转化

直播带货、达人专场、短直联动、直播间投流、坑产优化、场观人次、逼单转化。

## 3. 数据指标与效果

ROI优化、GMV、GSV、搜索进店、综合转化率、业绩目标。

## 4. 平台生态与全域联动

全域兴趣电商、抖音电商、小红书KOS、腾讯视频号、内容场、站外引流、抖音生态、腾讯KOS、IP账号。

## 5. 行业与品类

美妆医美、高端消费、轻医美、功效护肤、抗初老、美妆、日化、医疗、快消。

# 四、经历拆分与证据归属

分析前必须在内部将 `experience` 拆分为独立工作经历，每段分别识别：

- 任职公司或品牌；
- 岗位名称；
- 任职时间；
- 达人、KOL、直播、内容或商务职责；
- 团队、预算、渠道、达人资源和管理范围；
- 数据指标和业绩结果；
- 证据不足或风险。

公司、岗位、职责和业绩只有属于同一段经历时才能组合。禁止把不同公司的岗位、职责或业绩拼接为一段证据。

目标品牌可以是候选人的任职公司、明确负责的品牌或明确服务的客户，但必须区分：

- 品牌方直接任职属于强公司证据；
- 代理商、MCN、平台、广告公司或服务商经历，可以证明达人营销能力，但不能写成在目标品牌任职；
- 只出现合作品牌名称，没有候选人的具体职责时，不属于强证据；
- 产品名、项目名或技术名不能自动当作任职公司。

# 五、有效职责证据

有效职责应明确体现至少一项：

- 负责达人营销策略或达人业务规划；
- 搭建、管理或分层运营达人矩阵；
- 开拓、维护KOL、KOS、MCN或达人资源；
- 负责达人招商、选品、商务谈判、合同或佣金机制；
- 负责达人专场、直播带货、短直联动或直播间投流；
- 负责抖音、小红书、视频号或其他内容平台增长；
- 管理团队、预算、渠道、项目或经营目标；
- 对GMV、GSV、ROI、转化率、坑产、场观或业绩目标负责；
- 建立达人孵化、资源库、分层管理或效果归因体系。

“负责相关工作”“维护达人关系”“协助直播”“完成公司任务”等空泛描述不能作为强职责证据。

# 六、有效业绩证据

有效业绩应尽量包含指标名称、数值、时间或业务范围，并能合理归属于候选人的职责。

必须遵守：

- 没有指标名称的数字不得解释为GMV、GSV、ROI、销售额、利润或个人业绩；
- 公司整体销量、排名、规模和累计成绩不得写成候选人个人业绩；
- 只有原文明确说明候选人负责、主导或推动某项结果时，才能作为个人岗位业绩；
- 无法确认口径时，只能写“该数字未注明指标名称和归属范围”；
- 不得根据外部知识推断品牌级别、客单价、市场地位或母子公司关系。

# 七、匹配结论

先根据证据确定 `match_result`，再评分。评分不能替代证据判断。

## relevant

必须同时满足：

1. 输入明确出现“统招本科条件：满足”；
2. `match_score >= 80`；
3. `role_evidence >= 42`；
4. 岗位名称严格命中或职责能够证明岗位高度相关；
5. 至少有两类达人营销核心能力证据，例如达人资源、商务BD、直播转化、平台运营、数据归因；
6. 至少有一项负责人级证据，例如团队、预算、策略、渠道、经营目标或可归属的量化业绩；
7. 证据来自同一段或边界清晰的多段经历，没有错误拼接。

输出：

- `beauty_relevant = true`
- `match_result = "relevant"`

## needs_review

出现以下任一情况时输出：

- 岗位名称相关，但具体达人营销职责不足；
- 有达人、KOL或直播经历，但不能确认候选人承担负责人级责任；
- 只有资源词、平台词或指标词，没有明确职责归属；
- 公司、岗位、职责或业绩的经历边界不清；
- 大概率相关但总分不足80，或 `role_evidence` 不足42；
- `experience` 为空、缺失、不是字符串或无法拆分有效经历。

输出：

- `beauty_relevant = false`
- `match_result = "needs_review"`

## not_relevant

出现以下任一情况时输出：

- 没有达人、KOL、KOS、MCN、直播电商、内容商务或相关运营证据；
- 只有传统品牌、销售、医疗、市场、媒介或BD经历，但没有达人营销方向职责；
- 岗位名称宽泛且工作内容与达人营销无关；
- 只有行业词或品牌词，没有目标岗位证据；
- 工作内容明确属于非目标职能。

输出：

- `beauty_relevant = false`
- `match_result = "not_relevant"`

强制对应：只有 `match_result = "relevant"` 时，`beauty_relevant` 才能为 `true`。

# 八、100分评分标准

为兼容现有工作流，必须保留以下三个评分字段。

## industry_depth：0—25分

评估候选人在目标行业和品牌类型中的业务深度：

- 21—25：长期或多段任职于美妆医美、高端消费、医疗健康、个护或快消企业，且直接负责相关增长、内容、达人或电商业务；
- 15—20：至少一段明确目标行业经历，或多段服务目标行业客户的经历；
- 8—14：只有局部项目、客户或产品经验；
- 1—7：只有模糊行业词；
- 0：没有可确认的目标行业经历。

仅服务客户、没有直接经营责任时，本项最高18分。仅出现品牌或产品名称时最高8分。

## beauty_continuity：0—15分

字段名为兼容现有系统保留，实际评估“目标行业及达人营销经历连续性”：

- 13—15：累计五年以上或至少三段较连续相关经历，最近仍在相关方向；
- 9—12：累计三至五年或至少两段较连续相关经历；
- 5—8：有一段一年以上经历，或多段短期相关经历；
- 1—4：只有短期项目或时间信息模糊；
- 0：没有相关经历。

没有任职时间信息时最高8分；只有一次短期客户项目时最高4分。

## role_evidence：0—60分

评估达人营销岗位职责、管理责任和结果证据：

- 52—60：岗位明确，达人营销职责完整，同时有达人矩阵、商务资源、直播转化、平台运营、团队管理和有效业绩中的多项强证据；
- 42—51：能够证明承担目标岗位大部分核心职责，并有负责人级责任或有效结果证据；
- 30—41：有明确达人、KOL或直播职责，但管理范围、策略责任或业绩不完整；
- 15—29：只有部分执行职责、平台经验或笼统达人资源描述；
- 1—14：只有零散关键词，无法证明真实承担相关职责；
- 0：没有目标岗位证据或职责明确无关。

限制：

- 只有岗位名称，没有职责和有效业绩，最高15分；
- 只有执行、协助或配合职责，最高25分；
- `BD负责人`、`BD总监`、`媒介总监`没有达人/KOL/直播方向证据，最高20分；
- 没有团队、预算、策略、经营目标、渠道责任或有效业绩，最高40分；
- 无口径数字不能进入42分以上区间。

必须满足：

`match_score = industry_depth + beauty_continuity + role_evidence`

三个分项和总分均必须为整数，总分范围0—100。

# 九、analysis_reason与evidence_summary

`analysis_reason` 必须依次说明：最终结论、岗位相关性、达人营销核心职责、管理或经营责任、量化结果、关键风险。不得使用没有原文依据的“经验丰富”“能力突出”等评价。

`evidence_summary` 必须是字符串数组，建议输出3—6条，分别描述：

- 公司、品牌和任职时间；
- 岗位名称；
- 达人/KOL/直播/商务职责；
- 团队、预算、渠道或经营责任；
- 有效业绩；
- 证据不足或风险。

所有证据必须来自 `experience` 原文，不得编造、补全或跨经历拼接。没有有效证据时输出空数组。

# 十、固定输出

只输出一个合法JSON对象，不得输出Markdown、代码块、标题、解释、注释、前言或后记。

顶层字段必须严格且仅包含以下6个字段：

- `beauty_relevant`
- `match_result`
- `match_score`
- `score_breakdown`
- `analysis_reason`
- `evidence_summary`

`score_breakdown` 必须严格且仅包含：

- `industry_depth`
- `beauty_continuity`
- `role_evidence`

输出前自行检查：

1. JSON合法且字段完整；
2. `match_result` 只能是 `relevant`、`needs_review`、`not_relevant`；
3. `industry_depth` 为0—25；
4. `beauty_continuity` 为0—15；
5. `role_evidence` 为0—60；
6. 三个分项之和严格等于 `match_score`；
7. `match_score` 为0—100；
8. `relevant` 时总分不低于80且 `role_evidence` 不低于42；
9. `beauty_relevant` 与 `match_result` 强制对应；
10. 没有跨经历拼接，也没有把无口径数字解释为GMV、GSV、ROI、销售额或利润。
