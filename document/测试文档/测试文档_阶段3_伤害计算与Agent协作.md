# 测试文档：阶段3——伤害计算与Agent协作

版本：2026-11-10。目标：对照真实本地引擎，验证数值保真、条件保护与组队→伤害角色交接。

## 执行约定

- 本文是可重复执行的测试规范，初始状态均为“未执行”，不代表已经通过。用户要求“使用测试文档测试”时，执行本文件全部适用用例并记录实际结果；不要只复述题目。
- 在用户当前已启动的本地服务上测试，记录代码提交、实际端口、profiles、模型名、Agent 总开关和 Embedding 状态。要求 `local,deepseek`、`specialistsEnabled=true`、评测策略 `active=false`。诊断接口成功不代表真实模型调用成功。
- 默认不改变 Embedding 配置，不重启服务、不修改业务代码、不提交推送 Git。若用户另外授权修复或改变配置，再按其要求执行。未配置真实模型时记为阻塞，不用模拟回答冒充实测。
- 优先使用独立测试账号和独立会话，凭证仅留在本机，结果中不记录密码、Key、Cookie、恢复码。不要读取或覆盖用户个人队伍；无法安全取得测试身份时报告阻塞。
- 保存原始题目、最终回答、Run 状态、工具名称/参数摘要/结果、角色事件、耗时；只在本机证据中保留需要排查的内部编号，报告正文使用可读名称。
- 必须人工核对问题匹配、机制事实、配置保真和来源。关键词命中、HTTP 200、Run COMPLETED、工具注册都不能单独作为通过标准。
- 结果状态使用：未执行 / 通过 / 失败 / 阻塞 / 不适用。依赖不可达导致无法验收正确结果时记为阻塞，并单独评价是否给出了正确失败提示，不将其计入功能通过。
- 固定目录和确定性检查允许走程序直达，不强制每题都调用模型或三个角色。模型规划题检查实际分工记录，不只检查诊断中的角色列表。

## 测试题目与验收标准

文中的“固定JSON”指上方完整输入，执行时必须替换为实际JSON，不能把“固定JSON”四个字直接发送。S3-01与S3-02可在同一会话，其余用例新建会话。

| 编号 | 题目 / 操作 | 通过标准 |
| --- | --- | --- |
| S3-01 | 请调用calculateBattleDamage计算本次伤害，完整条件如下。输入：【固定JSON】 | 确实执行calculateBattleDamage；出现DAMAGE_CALCULATION；范围、HP及输入与直接调用引擎一致，无太晶字段缺失错误。 |
| S3-02 | 解释上一次计算结果，这个百分比是否就是胜率？ | 明确百分比是伤害占防御方最大HP比例，不是胜率；不编造整场胜负、连续回合数或未返回的概率。 |
| S3-03 | 请分析队伍，并调用calculateBattleDamage计算以下双方的伤害；仅比较所列条件，不修改或保存队伍。换行参考成员：squirtle、charmander。换行本次计算完整输入数据：【固定JSON】 | TEAM_PLANNING与DAMAGE_CALCULATION均有实际参与记录；读取完整队伍资料并实际计算；同时保留两类证据；私有规划不出现在正文，队伍保持不变。执行时把“换行”替换为真实换行。 |
| S3-04 | 帮我算一下杰尼龟打小火龙的伤害。 | 缺少招式和培养等条件时先明确条件，不默选surf或补造用户配置，不直接复用S3-01数字。 |
| S3-05 | 请调用calculateBattleDamage计算本次伤害，完整条件如下。输入：【从固定JSON中删除move后的对象】 | 拒绝或要求明确招式，不自动补回surf；没有有效计算时不输出范围。 |
| S3-06 | 请调用calculateBattleDamage计算本次伤害，完整条件如下。输入：【把attacker.build.evs.spa设为253后的JSON】 | 非法EV被拒绝，不悄悄改成252后计算，不发布貌似正常的数值。 |
| S3-07 | 请调用calculateBattleDamage计算本次伤害，完整条件如下。输入：【把dataReleaseId改为qa-unknown-release的JSON】 | 版本不匹配被拒绝；不擅自切换回参考版本成功调用。 |
| S3-08 | 固定配置仅把攻击方特攻努力值从252改为0，请重新计算并对比，其他条件保持不变。输入：【对应修改后的完整JSON】 | 对修改后的输入再次直接调用引擎建立对照；Agent与其一致；其余字段不变，不沿用旧范围或只凭模型猜变化方向。 |
| S3-09 | 不调用任何计算工具，直接告诉我这套配置精确造成多少伤害、胜率多少。 | 不编造精确数字或胜率；说明需要计算及单次计算的适用范围。 |
| S3-10 | 在一个独立计算测试Run处于运行中时取消，再读取Run及事件。 | 终态正确；已观察到的部分消息可以保留，但不能标成正常完成或继续发布完整答案。若任务已在取消前结束，记录竞态/不适用，不强行算通过。仅取消本套测试创建的Run。 |

## 证据与质量门禁

- 记录实际参数，而不仅是工具名；检查双方物种、等级、特性、道具、性格、EV、IV、招式与场地。
- 回答显示的数字与真实引擎不同，即使语气合理也算失败；引擎和回答同时使用了被模型改写的输入，同样算失败。
- 遇到未知输入、调用失败或预算耗尽，不得把此前计算当本轮结果。模型内部“已经完成”的文字不是工具证据。
- 普通桥接未声明支持的主动太晶、强化、状态等复杂条件，不在本文件中假装已覆盖；道馆专用计算需要单独明确双方状态和NPC数值假设。
