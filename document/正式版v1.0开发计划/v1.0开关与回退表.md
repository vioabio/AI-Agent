# v1.0 功能开关与回退表

> 默认安全策略：所有新链路和高风险能力关闭。每次打开开关前，必须先完成对应测试并保留证据。

| 配置键 | 默认值 | 作用 | 关闭时 | 回退动作 |
|---|---:|---|---|---|
| `vio.agent.v1.enabled` | `false` | 新 Run 主链灰度 | 走兼容只读端点 | 将配置改回 `false`，重启或刷新配置 |
| `vio.rag.pgvector.enabled` | `false` | PGVector 生产检索 | 仅使用测试/演示存储 | 禁用 PGVector，保留上一版索引 |
| `vio.mcp.enabled` | `false` | 远程 MCP 适配器 | 只使用本地白名单工具 | 关闭远程连接，检查 MCP 审计日志 |
| `vio.tools.high-risk.enabled` | `false` | 高风险管理工具 | 全部拒绝 | 保持关闭并复核审批记录 |

## 回退顺序

1. 先关闭对应开关，阻止新请求进入问题链路。
2. 保留当前 Run、Trace、错误日志和指标证据。
3. 恢复上一版应用配置/镜像；不要删除现有数据和索引。
4. 运行健康检查、只读接口和最小回归测试。
5. 在 `artifacts/v1.0/rollback/` 记录操作时间、操作者、commit、结果和后续修复项。
