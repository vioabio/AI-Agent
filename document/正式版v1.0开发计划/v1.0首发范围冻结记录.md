# VIO v1.0 首发支持矩阵冻结记录

> 冻结日期：2026-09-02  
> 冻结基线：`main@708126a691bd7a789ddb261d11bb464caa96a45e`  
> 目的：为数据、Prompt、检索、计算和评测提供唯一适用范围，避免跨版本混答。

## 1. 首发支持矩阵

| 维度 | 冻结值 | 版本键/备注 |
|---|---|---|
| 主游戏 | 宝可梦朱/紫 | `game_release_id=pokemon-scarlet-violet` |
| 补丁基线 | `source-snapshot-20260902` | 导入数据时必须记录来源公布的官方补丁号 |
| DLC | 零之秘宝 | `dlc_id=the-hidden-treasure-of-area-zero`；篇章必须显式选择 |
| 语言 | 简体中文 | `language=zh-CN`；英文/日文仅用于别名消歧 |
| 对战模式 | 剧情/休闲单打、剧情/休闲双打 | `battle_format_id=casual-singles/casual-doubles` |
| 竞技规则 | 一个经审核的 VGC 规则集 | `ruleset_version_id` 随数据发布单元固化 |
| 数据发布 | 主数据、文档、索引同批发布 | `data_release_id`、`knowledge_release_id`、`index_release_id` 必须可追溯 |

## 2. 明确不支持

- 其他世代与朱/紫数据混答。
- 实时天梯代打、账号操作、交易和未审核活动传闻。
- 未提供游戏、DLC、语言或赛制时的无条件猜测；缺失时先追问。

## 3. 冻结执行规则

1. 所有事实、RAG 文档、向量和答案必须携带上述版本键。
2. 数据导入阶段将 `source-snapshot-20260902` 映射为来源实际公布的补丁号，并写入数据发布记录。
3. 变更主游戏、DLC、规则集或补丁基线必须新建版本冻结记录，不直接覆盖本记录。
