## 2. 发布阻断规则

以下任意一项未通过，发布状态必须为 BLOCKED：

- [ ] 后端或前端测试存在 failure/error。
- [ ] 确定性计算、数据库约束、资源级权限或安全红队存在回归。
- [ ] 高风险工具出现未审批执行、越权执行或审计缺失。
- [ ] Run 出现多终态、事件乱序、断线丢失或 cancel 不生效。
- [ ] 质量指标没有样本量、版本、统计窗口或可复查报告。
- [ ] readiness 未通过、镜像不可复现、备份恢复或回滚未演练。

## 3. 产品范围与正确性

- [ ] 首发游戏、补丁、DLC、语言、赛制和数据截止时间已冻结。
- [ ] 超出支持矩阵的问题会澄清、拒答或给出明确替代路径。
- [ ] 图鉴、形态、种族值、特性、招式、进化和版本可用性来自结构化数据。
- [ ] 每个事实答案返回适用版本、data release 和来源。
- [ ] 缺少游戏/形态/赛制时不会由模型自行猜测。
- [ ] 双属性、免疫、特性、太晶和伤害边界由代码计算。
- [ ] 队伍合法性覆盖合法/非法样例、禁用成员、重复招式和努力值边界。
- [ ] 攻略答案返回 document version、chunk、source URL 和 evidence text。
- [ ] 无证据、来源冲突和过期内容会拒答或追问。
- [ ] 用户可以保存、读取和删除会话、队伍和收藏。
- [ ] 反馈可以从提交进入分级、审核、修订、评测、发布、重答和关闭。

## 4. 数据与发布

- [ ] 所有 Flyway/SQL migration 可从空库顺序执行。
- [ ] 稳定身份与版本事实分离，已发布事实不会被原地 UPDATE 覆盖。
- [ ] 主键、外键、唯一键、有效期和状态约束由数据库强制。
- [ ] 外部数据记录 source、license、trust_level、checksum、retrieved_at 和 owner。
- [ ] 冲突进入 quarantine 或人工审核，不发生静默覆盖。
- [ ] 文档切块、Embedding 和索引都有 profile 与 checksum。
- [ ] ingestion job 可重试、可观察，失败不会影响旧 release。
- [ ] 候选 data/knowledge/index release 通过黄金集后才切换 active 指针。
- [ ] 发布、撤回、回滚和通知都有操作人、时间和审计记录。

## 5. Agent Run 与事件

- [ ] Run 状态只允许 CREATED → RUNNING → WAITING_APPROVAL → 终态。
- [ ] 每个 Run 恰好产生一个 run.completed/failed/cancelled/timed_out。
- [ ] eventId 在 Run 内单调递增，runId+eventId 唯一。
- [ ] 事件包含 schemaVersion、sessionId、runId、traceId、timestamp 和 payload。
- [ ] POST 创建返回 202、runId 和 eventsUrl。
- [ ] GET 事件支持 afterEventId 和 Last-Event-ID。
- [ ] 浏览器断线不会隐式取消 Run。
- [ ] 显式 cancel 具备认证、CSRF、幂等和超时语义。
- [ ] 事件超出保留期返回明确 410 Gone。
- [ ] 服务重启后可查询已完成 Run、消息和 Checkpoint。
- [ ] 模型、工具和整体 Run 的超时与取消令牌可独立验证。
- [ ] 终态后不再发送 answer.delta 或 tool.started。

## 6. 工具、MCP 与安全

- [ ] 每个工具有 name、version、riskLevel、sideEffect、idempotent、timeout 和 allowedRoles。
- [ ] 工具执行顺序包含身份、白名单、Schema、出网/路径策略、HITL、幂等、超时、脱敏和审计。
- [ ] 玩家工具与运营/管理员工具分离注册。
- [ ] 公网默认没有 Shell、任意文件写入、任意下载和无约束网页抓取。
- [ ] 未知工具、未知参数、路径穿越、命令注入和 SSRF 均 fail-closed。
- [ ] 中/高风险写操作进入 WAITING_APPROVAL，不能自动批准。
- [ ] 审批绑定 userId、runId、工具版本、参数摘要和过期时间。
- [ ] 重试只作用于幂等读操作或明确安全的调用。
- [ ] 每次工具调用都有 tool_execution、traceId、耗时和最终结果。
- [ ] MCP 关闭时主应用仍可启动。
- [ ] MCP 开启时只有一条生产接入路径，且凭据、受众、超时和审计有效。
- [ ] 自研 MCP 实验代码没有绕过生产治理网关。

## 7. 身份、会话与隐私

- [ ] 浏览器不在 URL、历史、日志或 localStorage 保存 API Key。
- [ ] 生产 Secret 缺失时启动失败，仓库没有公开 fallback。
- [ ] Session Cookie 设置 Secure、HttpOnly、SameSite 和短 TTL。
- [ ] 写接口校验 CSRF 与 Origin/Referer。
- [ ] 用户、会话、队伍、反馈、知识和工具资源做资源级授权。
- [ ] 管理接口有独立角色、审计和最小权限。
- [ ] 长期偏好有用户授权、来源、置信度、TTL 和删除入口。
- [ ] 会话删除在主库和备份保留策略中都有明确语义。
- [ ] 日志、事件和错误响应完成敏感字段脱敏。

## 8. 前端体验

- [ ] 选择版本、DLC、语言、赛制和查询目标的输入项可用。
- [ ] 图鉴、配招、计算、队伍、引用和错误卡能渲染。
- [ ] creating/running/waiting_approval/reconnecting/终态均有 UI。
- [ ] 同一会话在非终态启用单飞锁。
- [ ] 每个 Run 独立保存连接、AbortController、游标和视图状态。
- [ ] 断线可从最后 eventId 重连，不重复、不丢事件。
- [ ] 显式 cancel 后停止正文输出并恢复输入。
- [ ] 无证据、版本冲突、429、认证失败和会话过期有明确提示。
- [ ] 关闭页面或切换路由会释放流、计时器和监听器。
- [ ] 前端 API DTO、OpenAPI 文档和后端事件 schema 一致。
- [ ] npm ci、lint、typecheck、unit、build 和 E2E 均纳入 CI。

## 9. 评测与指标

- [ ] 事实集至少 200 题并有人工答案。
- [ ] 计算集覆盖全部组合和边界，程序断言 100%。
- [ ] 合法性集至少 100 组。
- [ ] RAG 集至少 100 题，记录 Recall@5、引用正确率和 Groundedness。
- [ ] 无答案集至少 50 题，记录拒答/澄清正确率。
- [ ] Agent 工具集至少 50 个任务。
- [ ] 安全红队集至少 100 条。
- [ ] 每次 evaluation_run 记录代码、模型、Prompt、数据、索引、环境和样本量。
- [ ] 确定性任务不使用 LLM-as-Judge 代替断言。
- [ ] 指标字典包含公式、分母、排除项、窗口、负责人、阈值和回滚条件。
- [ ] TTFT、P50/P95、Token、成本、工具、检索和反馈指标可按场景分桶。
- [ ] 任何对外数字都能回到一份不可变报告。

## 10. 观测与运维

- [ ] traceId 贯穿浏览器、API、Run、检索、模型、工具和数据库。
- [ ] Actuator liveness/readiness 与 Prometheus exposition endpoint 可访问。
- [ ] Prometheus Targets 为 UP，Rules 和 Alerts 已加载。
- [ ] Grafana datasource、dashboard 和告警配置随仓库版本化。
- [ ] 人为制造模型、数据库、MCP 或索引故障能触发告警。
- [ ] 日志包含业务键、状态和异常堆栈，不泄露敏感信息。
- [ ] Run、工具、审批和反馈审计可按 traceId 查询。
- [ ] agent_event、详细 Trace、会话和审计的保留期符合规格。
- [ ] 备份加密、权限受控，恢复操作可审计。

## 11. 构建、部署、恢复

- [ ] 干净 checkout 能完成后端 compile/test。
- [ ] 前端使用 npm ci，构建不依赖开发者本机缓存。
- [ ] 后端和前端镜像采用多阶段构建，镜像可用 digest 标识。
- [ ] docker compose config 无未解析变量和 Secret 默认值。
- [ ] Compose 启动后数据库、后端、前端和监控健康。
- [ ] readiness 检查必要数据版本和依赖，不只检查进程端口。
- [ ] Nginx 的 /api、SPA 和 SSE 路径已用 HTTP 实测。
- [ ] CI 失败不会被 continue-on-error 静默吞掉。
- [ ] 部署后有固定事实题、计算题和事件流冒烟。
- [ ] RPO/RTO 通过故障模拟与恢复探针测量。
- [ ] 上一镜像、迁移、数据/知识/索引 release 可在规定时间回退。

## 12. 最终演示脚本

- [ ] 0:00 选择朱/紫、DLC、语言和赛制。
- [ ] 0:20 查询图鉴，展开版本和来源。
- [ ] 0:50 提交属性/伤害计算，展示输入、公式版本和结果。
- [ ] 1:20 导入六人队伍，展示合法性、弱点和速度线。
- [ ] 1:50 查询攻略，展示混合检索、引用和无证据拒答。
- [ ] 2:15 提交纠错，展示运营审核、发布候选和定向评测。
- [ ] 2:35 重新提问，展示新知识版本和重答通知。
- [ ] 2:50 打开 Trace/Grafana，展示 TTFT、P95、Token、成本和工具审计。
- [ ] 3:00 触发回滚，展示上一镜像与索引恢复记录。
