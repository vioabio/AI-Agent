# M6～M7 交付说明（评测、可观测、容器与恢复）

日期：2026-09-02  
范围：`evaluation/`、`observability`、监控配置、CI、Docker/Compose 和发布/恢复证据模板。

## 已落地

### M6

1. `evaluation/manifest.json` 固定七类评测套件、最低样本规模和候选阈值。
2. `evaluation/datasets/*.jsonl` 提供脱敏、可运行的契约样例；样例不是生产成绩。
3. `evaluation/quality_gate.mjs` 提供 `ci` 和严格 `release` 两种模式：
   - `ci` 检查 JSONL、版本键、唯一 caseId 和红队期望值；
   - `release` 额外检查最低样本、`ready` 状态、不可变评测报告和指标阈值。
4. `evaluation/metric-dictionary.json` 登记公式、分母、排除项、窗口、最小样本、阈值和回滚条件。
5. `evaluation/contracts/` 固化反馈纠错状态机和 evaluation run 契约。
6. `AgentMetrics` 在保留诊断快照兼容性的同时绑定 Micrometer；Prometheus 采集入口为 `/api/actuator/prometheus`。
7. Prometheus rule、Alertmanager 配置和 Grafana datasource/dashboard 随仓库版本化。

### M7

1. 后端 Dockerfile 使用 Maven build stage + 非 root JRE runtime；前端使用 `npm ci`，运行时采用 `nginxinc/nginx-unprivileged` 非 root 镜像。
2. 镜像内和 Compose 均使用 readiness 探针；Nginx 不再使用不会展开的 shell 变量。
3. Compose 对数据库、应用和监控服务提供健康检查；密码/API Key 缺失时启动配置解析失败，不使用公开默认密码。
4. CI 顺序包含后端 compile/test、前端构建、契约/评测检查、Secret 扫描、镜像构建和 Compose 冒烟。
5. Release workflow 在严格评测通过后生成包含 commit、镜像标识、模型/Prompt/数据/索引版本的发布清单。
6. `ops/recovery/README.md` 与 `ops/recovery/recovery-drill.ps1` 固化删除容器、数据库恢复、固定探针、RPO/RTO 记录格式（脚本默认 dry-run）。

## 本机验证

```powershell
node evaluation/quality_gate.mjs --mode=ci --report artifacts/v1.0/eval/20260902-M6-contract-report.json
node evaluation/create-release-manifest.mjs --release local-m6-m7
# 全新 checkout 先安装前端锁定依赖，再使用其中的 js-yaml 做静态解析
Set-Location vio-ai-agent-frontend
npm ci
Set-Location ..
node -e "const fs=require('fs'),yaml=require('./vio-ai-agent-frontend/node_modules/js-yaml'); for(const f of ['docker-compose.yml','prometheus.yml','alert-rules.yml','alertmanager.yml']) yaml.load(fs.readFileSync(f,'utf8')); JSON.parse(fs.readFileSync('grafana-dashboard.json')); console.log('config parse OK')"
```

上述命令只证明静态契约和配置可解析，不代表服务已经上线。Docker 当前不可用，因此 `docker compose config/up`、镜像构建、Actuator 实际响应、Prometheus Target/Rules/Alerts 和恢复演练均保持 `待现场验证`。严格 release 门禁也会因为当前样例套件为 `scaffold`、没有完整评测报告而失败，这是预期的安全行为。发布工作流目前只能生成本地镜像 ID；接入仓库后还必须回填不可变 digest、SBOM/签名和目标环境 smoke test。

## 回滚点

- 诊断 JSON 保留在 `/api/metrics`，标准采集改用 Actuator；可独立关闭监控 profile。
- 新镜像发布前必须保存上一份 release manifest；readiness 未通过不切流。
- 索引按 `active_index_release` 指针回退，数据库按备份/向前兼容迁移恢复。
