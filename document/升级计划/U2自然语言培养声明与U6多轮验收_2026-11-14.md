# U2自然语言培养声明与U6多轮验收

## 本轮开发

培养条件此前主要依赖“游戏：朱；目标：阿枫初战”等标签。本轮在`TrainingIntentState`内补充有限、确定性的第一人称自然语言声明解析，沿用原有条件存储、冲突处理与培养核对，不增加模型调用，不修改保存队伍或当前Run版本。

支持示例：

```text
请为我的队伍ID 你的队伍ID制定培养计划，不保存，不修改。
我玩的是朱版，我刚拿到两枚徽章，我的目标是阿枫初战，我不想练级，我只用已有学习器。
```

| 明确声明 | 记录内容 |
| --- | --- |
| 我玩的是朱版 / 我正在玩紫版本 | 游戏声明 |
| 我刚拿到两枚徽章 / 我已经拿到2枚徽章 | 徽章2、进度2枚徽章，均为用户声明 |
| 我的目标是阿枫初战 / 我的目标是奇树重赛 | 指定馆主与明确阶段；重赛统一显示视察重赛 |
| 我不想练级 / 我不练级 | 不允许练级 |
| 我允许练级 / 我最多练到55级 | 允许练级，或允许到明确上限；不自动设置目标等级 |
| 我不使用道具 / 我不制作学习器 / 我只用已有学习器 | 对应资源限制 |
| 我把目标改为奇树重赛 / 我把游戏版本改为紫版 | 对该字段的明确更新 |

数字徽章支持0～8及零、一、二、两等对应中文单字。等级只接受1～100的明确整数。自然语言未覆盖任意游戏、全部进度、任意目标或自由描述。

## 保守边界

- 只从本会话传入的用户消息中重建，最多复用最近64条用户消息；助手、系统、工具输出不作为用户许可。
- 带引用、资料、示例、假设、攻略、转述、队友建议、对手条件或问题标记的自然语言不采用。明确标签仍沿用原有解析；不把本次增强描述为所有自然语言或引用攻击都已解决。
- 含冒号的消息保留原标签语义，不混合抽取；资源字段里的逗号不会被拆成新许可。
- 前后不一致继续标记冲突，不默认采用最近一句；可用原有“练级改为：允许到55级”等标签明确纠正，“练级：未知”清除声明。
- “最多练到55级”是上限，不是目标等级，也不证明保存成员已经55级；“不使用道具”不解释为允许制作学习器。
- 未说明馆主或阶段时不猜测；没有查询游戏存档、库存或实际解锁，没有自动写入队伍、创建审批或授予权限。
