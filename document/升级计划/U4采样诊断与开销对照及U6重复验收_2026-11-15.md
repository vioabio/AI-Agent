# U4 采样诊断、开销对照与 U6 重复验收

## 本轮完成

补齐运行诊断及公开配置指纹中的领域追踪采样率，修复采样配置差异可能被单开关对照忽略的问题。增加完整父子链采样回归、本地 SDK 固定工作量探测，以及实际网页服务的两轮追踪开关对照。

U6 已接入采样配置检查。比较 `domainTracing` 开关时，两组必须记录相同采样率且关闭自动追踪。缺少该项的历史报告会要求重新采集。

## 改动位置

| 文件 | 内容 |
| --- | --- |
| `LocalRuntimeController.java` | 新增 `domainTracingPolicy`，提供配置采样率、自动追踪开关和配置范围 |
| `upgrade-baseline.mjs` | 仅提取合法的数值采样率和布尔自动追踪开关参与公开指纹 |
| `upgrade-switch-compare.mjs` | 领域追踪对照要求明确的采样配置，其他配置差异仍拒绝配对 |
| `start-ablation-backend.ps1` | 增加 `-DisableDomainTracing` 和 `-TracingSampleRate`，使用独立端口及数据目录 |
| `AgentTracingConfigurationTest.java` | 增加 25% 采样完整树检查，以及外部已采样上下文无法覆盖领域 0% 配置的回归 |
| `AgentTracingOverheadTest.java` | 显式开启的本地 SDK 耗时探测，保存原始纳秒样本、采样及导出计数 |

`domainTracingPolicy` 反映已配置的策略。该接口的范围为本机诊断，采样策略是否生效通过实际 SDK 导出与 Jaeger 查询交叉核对。公开配置只保留受控字段，导出地址、请求头和凭据继续由运行环境管理。

## 采样与导出验证

- 25% 采样连续执行 128 个领域根任务，逐批清空导出队列，核对每条保留链恰好包含根、授权阶段和模型三个 Span，子节点归属同一根。
- 外部 HTTP 上下文为已采样时，领域 0% 配置仍产生零导出，业务返回值正确，外部线程上下文恢复。
- 本地探测每种模式预热 32 次、测量 64 次，重复 3 轮并轮换模式顺序。模式包括关闭追踪、0%、25%、100% 采样及导出器返回失败。
- 探测每种模式的业务执行次数均为 96，100% 模式每轮导出 288 个 Span。导出失败模式仍执行全部业务调用。

探测使用真实 Micrometer/OTel SDK 与受控导出器，记录固定函数工作量，队列清空在计时区间外。结果包含 JVM 预热、分配和测试断言开销。输出保留每轮中位数、P95 和原始样本，性能阈值不参与测试通过判断。

## 实际服务开关对照

两个隔离服务分别监听 `18124` 与 `18125`，使用相同已测试产物、DeepSeek 配置、Skills、上下文装配、BM25 及采样率 1，分别关闭和开启领域追踪。

选择 4 道已有开发题，共 5 轮，按关闭、开启顺序采集，随后再重复一次。每次使用新的隔离账号与会话。

| 开发题 | 核对内容 |
| --- | --- |
| `U0-RETRIEVAL-02` | 通用组队检索实际原创攻略，工具范围仅攻略检索 |
| `U0-CONVERSATION-01` | 按等级展示馆主，再承接第 7 位莉普的初战配置 |
| `U0-CALCULATION-01` | 电对水／飞行为 4 倍 |
| `U0-AUTHORIZATION-04` | 拒绝显示系统凭据，实际无凭据读取调用 |

两轮开关对照累计 20 轮正文经 AI 辅助复核通过。各组的事件 Run 身份、顺序、正文拼接、摘要及完成终态校验通过。开启组 10 个 Run 均关联实际 Jaeger 链路，关闭组在本次查询窗口内均未找到对应领域链路。关闭组链路脚本退出 1，报告记录 `NOT_FOUND`，符合该组配置。

保留的 HTTP 轮询耗时中，第一对的逐轮总耗时差中位数为 49ms，第二对为 30ms。每对只有 5 轮，模型响应时长有波动，采集期间还有整体回归运行，性能结论保持待评估。后续应在固定负载、独占资源与更多交替样本下继续测量。

## 复现步骤

先在独立目录运行已配置 JDK 的离线定向测试，输出报告使用新文件名。

```powershell
.\mvnw.cmd -o -B -ntp '-Dvio.build.directory=artifacts/新的采样构建' '-Dtest=AgentTracingConfigurationTest,AgentTracingOverheadTest,LocalRuntimeControllerTest,AgentToolDispatchObservationTest' '-Dvio.tracing.probe=true' '-Dvio.tracing.probe.output=artifacts/新的SDK探测.json' test
```

探测默认关闭，显式开启时需要提供新的 `artifacts` 根目录下 JSON 输出文件。记录运行时 JDK 和系统版本，编译继续遵循项目 Java 21 配置。

使用该构建启动两个服务。

```powershell
.\ops\local\start-ablation-backend.ps1 -BuildDirectory artifacts/新的采样构建 -OutputDirectory artifacts/新的关闭服务 -Port 18124 -Skills -ContextAssembly -DisableDomainTracing -TracingSampleRate 1
.\ops\local\start-ablation-backend.ps1 -BuildDirectory artifacts/新的采样构建 -OutputDirectory artifacts/新的开启服务 -Port 18125 -Skills -ContextAssembly -TracingSampleRate 1
```

依次采集两组，使用相同开发题 ID，再生成对照。

```powershell
node tools/campus/upgrade-collect.mjs artifacts/新的关闭采集 http://127.0.0.1:18124/api 4 U0-RETRIEVAL-02,U0-CONVERSATION-01,U0-CALCULATION-01,U0-AUTHORIZATION-04
node tools/campus/upgrade-collect.mjs artifacts/新的开启采集 http://127.0.0.1:18125/api 4 U0-RETRIEVAL-02,U0-CONVERSATION-01,U0-CALCULATION-01,U0-AUTHORIZATION-04
node tools/campus/upgrade-switch-compare.mjs artifacts/新的关闭采集/baseline.json artifacts/新的开启采集/baseline.json domainTracing artifacts/新的追踪对照.json
```

开启组配合本地 Jaeger 查询实际链路。正文逐轮复核后单独保存摘要绑定的内容评审。最终按进程元数据核对 PID 与启动时间，再关闭本次创建的两个服务。
