# U6 夜间开发与验收记录

本轮对应升级分支 `codex/v1.1-agent-upgrade`，交付内容包括外部 MCP 取消传播、新题质量修复、持续运行验证与早间交接。用户需处理的配置和人工体验见 [明早操作清单](明早操作与夜间交付清单_2026-11-15.md)。

## 外部 MCP 取消传播

在现有工具网关和 Spring AI MCP 回调之间增加取消桥接。

1. `McpCancellationConfiguration` 装饰现有 `NamedClientMcpTransport`，沿用原客户端连接和生命周期。
2. `CancellableMcpToolCallback` 保留工具定义、元数据、调用上下文和返回文本，在一次阻塞调用内建立请求作用域。
3. `McpCancellationTransport` 记录本次实际发出的 `tools/call` 请求编号，取消通知沿用原始字符串或数字编号。
4. 线程中断、SDK 超时或取消异常触发 `notifications/cancelled`，每个作用域只持有自己的请求绑定。
5. 通知使用有界异步发送，单连接最多64个在途通知，发送期限2秒，每个调用作用域最多16个绑定。

本轮针对固定的 MCP Java SDK 0.10.0 与 Spring AI 1.0.0 完成验证。工具白名单仍由原网关校验，业务修改继续经过预览和页面确认。

### 端到端证据

Spring HTTP 测试连接了真实 Run 生命周期、工具网关、Spring AI 标准同步回调、官方 SDK 和 STDIO 服务，分别覆盖以下场景。

| 场景 | 核对结果 |
| --- | --- |
| 用户取消 Run | Run 取消、取消通知发送、远端工作停止，同一连接的新查询成功 |
| Run 达到4秒截止时间 | Run 超时、远端工作停止，恢复查询成功 |
| 工具达到5秒执行期限 | 工具失败、远端工作停止，正文如实说明失败，恢复查询成功 |
| 已结束任务 | 取消/超时后重新核对事件，未发布迟到完整答案 |
| 并发作用域 | 取消一个请求时另一个请求继续运行 |
| 回调契约 | 同步及异步标准回调、元数据、ToolContext 和请求编号类型保留 |

HTTP 测试使用受控模型和公开资料替身，并在测试配置中将远端查询映射为已有的 `web_search` 只读能力。业务默认配置沿用当前 MCP 开关和白名单。实际测试范围为 STDIO 取消链路。

`written` 记录取消通知发送完成。远端工作停止另由服务端标记和同连接恢复查询核对。

## 持续运行范围

对项目正式 `PokemonMcpServerMain` 入口执行3600秒有界频率持续运行。使用已校验的公开资料缓存，每秒进行两次顺序 ping，每60轮查询图鉴并执行确定性伤害计算，同时短暂停止消费 stdout，随后恢复工具发现。

记录客户端和 Java 服务端 RSS、在途请求数、成功查询、协议无效帧、重复响应及关闭方式。运行期间机器还执行其他回归，资源数据按共享本机环境解释。该负载用于观察持续运行与恢复，吞吐上限和内存泄漏结论需另行设计测量。

持续运行所用构建与最终构建的 MCP 包37个组件摘要核对一致，其他业务代码的最终身份另由78组件清单核对。

实际运行3600.394秒，完成7102次ping、60次图鉴查询、60次伤害计算。无效帧0、重复响应0，正常关闭。客户端RSS首样64.89 MiB、末样70.44 MiB，服务端首样202.11 MiB、末样442.97 MiB；未应用内存稳定性门槛。完整采样归档于 `evaluation/upgrade-v1.1/u6/mcp-hour-soak-20261115.json`。
