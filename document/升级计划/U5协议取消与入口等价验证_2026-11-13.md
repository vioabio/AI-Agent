# U5 协议取消与入口等价验证

日期：2026-11-13。延续本地只读 STDIO 实现，未开放公网端口、账号数据、队伍写入或任意命令。

## 本轮改动

新增 `McpWireControl`，在固定版本 SDK 0.10.0 的传输入口前处理信封，领域授权仍由既有 `ToolExecutionGateway` 执行。

| 关注点 | 行为 |
| --- | --- |
| 初始化 | 工具发现和调用必须在初始化完成后；初始化前的 ping 直接返回空结果，避免 SDK 等待初始化造成互等 |
| 原始报文 | 严格拒绝重复 JSON 字段、尾随内容和过深结构；畸形 JSON 返回脱敏的 -32700，随后仍可初始化和调用 |
| 取消 | `notifications/cancelled.params.requestId` 绑定当前请求；字符串与数字 ID 分开。取消返回一次 `MCP_REQUEST_CANCELLED` 工具错误结果，不重启生成或重试工具 |
| 取消与参数隔离 | 服务端生成内部调用标识，在进入领域参数前移除；客户端传入同名内部字段直接拒绝，不能指定服务端调用范围 |
| 断连 | EOF、重复活动 ID、超大报文触发连接关闭及活动工具取消；同一活动 ID 不允许重用，避免跨请求取消和重复回复 |
| 容量 | 同时最多 2 个工具请求，最多 16 个待回复 SDK 请求，回复写出后释放名额；超限返回 MCP_BUSY，未知通知不送入 SDK 队列 |
| 体积 | 原始输入每帧最多 24,576 字节；领域参数 16 KiB、领域结果 64 KiB；SDK 输出帧最多 256 KiB，以容纳 JSON 转义开销 |
| 输出 | 一整帧验证后才写 stdout，SDK 协议错误只保留错误码与固定说明；普通日志不能进入 stdout |

取消会中断治理网关的等待并取消其任务 Future。测试验证了可响应中断的公共资料读取会停止；不承诺 JVM 能强行杀死忽略中断的任意第三方代码。此类滞留任务仍受固定工具线程池及零排队限制。

初始化失败后建议重建本地连接；只支持明确声明的 MCP 2024-11-05 子集，ID 限制为整数或最多 128 字符的字符串，不声称兼容全部现代客户端。

## 验证方式

- `McpWireControlTest`：原始报文恢复、待回复上限、响应后释放、未知通知、ID 类型绑定、取消、EOF、重复 ID、错误脱敏及合法长输出。
- `ReadOnlyMcpStdioTest`：独立 Node 客户端经真实 SDK/治理网关调用三项工具；慢读取取消后检查工作停止标记，随后再次查询成功；80 个 ping 突发无重复回复。
- 真实进程故障测试：慢请求期间 EOF、重复活动 ID、未结束的超长输入，要求进程在时限内自行退出；前两种还核对工具停止标记。测试失败时的强制回收不计为通过。
- `McpDomainEquivalenceTest`：使用同一离线上游与真实领域服务，对照网页 Controller 方法和 MCP 网关的 JSON 结果。覆盖编号、英文名、中文名、未完整培养配置、普通伤害、零伤害，以及错误版本和错误世代拒绝。

入口等价测试不等于真实 HTTP 登录、CORS、浏览器联动或所有输入组合已全部验证。独立 Node 测试覆盖 wire 链路；Controller 对照覆盖领域输出，二者应分别解读。

## 发现并修正的问题

1. SDK 初始化前 ping 等待问题：传输层直接响应初始化前 ping，不让客户端和初始化互等。
2. 输入解析器的字符串长度限制不能复用于较大的合法输出，现独立配置输出解析上限。
3. 等价测试使用统一 JSON 序列化后比较，避免 Java LongNode 与 JSON IntNode 的内部类型差异被误判为业务值不同；不删除来源、摘要或时间字段。
4. 测试上游补充中文名称 CSV，避免离线替身缺少名称索引使中文查询产生假失败。
5. 原新增测试误把变化招式“跃起”当作零伤害输入，实际引擎应拒绝变化招式。已改用“水枪 + Harsh Sunshine”验证零伤害，并保留引擎的原拒绝规则。该天气输入是计算器边界条件，不代表朱紫中该配置可获得或合法。
