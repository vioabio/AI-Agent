## 实际发现与修复

### 种族值问题夹带无关物种

询问“大嘴鸥的种族值能否直接说明我这只的实际速度”时，研究角色额外读取奇鲁莉安，回答带入无关图鉴行。

现由 `GuideAnswerEvidence.statMeaningQuestion` 识别有限的概念解释问题，主 Agent 和专用角色均只提供 `searchPokemonGuides`。保留明确查询、计算、配招、组队等复合问题的原工具范围。即使关闭 Skills，这条约束仍生效。

新增测试覆盖概念问法、混合请求、缺少检索工具，以及专用角色尝试调用未开放的物种工具时的拒绝处理。

### 检索命中默认值片段后漏答概念

第二轮中，回答只展示默认等级和 EV/IV 片段，漏掉种族值与实际能力的区别。

概念解释现选择已取得并通过完整性校验的 `build-values-and-defaults-v1` 短文，展示完整原文，并明确标注原文范围。文档最长 2,000 个 Unicode 码点。来源不匹配或校验失败时，返回资料缺失说明。

新增回归直接构造该文档第二片段的有效引用，验证最终回答仍包含第一段的种族值与实际能力说明。

### 地域形态的中文入口与英文别名

中文“阿罗拉六尾”原先先读取 `/pokemon-species/37/`，正常图鉴入口缓存的是 `/pokemon-species/vulpix/`。外部连接异常时，已有英文物种缓存无法用于这一步。

地域形态入口现复用随包已校验名称索引，优先按物种 slug 读取缓存，再核对实际返回的物种 ID 与形态列表。

`RegionalFormName.normalizeQuery` 统一处理 `Alolan Vulpix`、`alolan-vulpix` 和 `vulpix-alola`。图鉴适配器与证据身份核对使用同一归一化逻辑。新增离线回归，验证中文和上述英文形式均返回 formId 10103，且不触发网络请求。

## U6 新增事件证据校验

`tools/campus/upgrade-event-evidence.mjs` 复用既有摘要与事件终态判定，校验以下字段与关系。

1. 事件文件名与题号、轮次对应。
2. 文件摘要与记录一致，文件和事件数量受限。
3. 每条事件绑定本轮 Run，事件 ID 严格递增。
4. `answer.delta` 拼接结果与保存正文完全一致。
5. 完成状态具有唯一且匹配的终态事件，拒绝冲突终态。

开关对照 CLI 为两侧写入 `eventEvidence`。当前构建清单的内容评审校验器同时执行逐轮检查。来源、正文及 Run 事件不一致时，校验失败。
