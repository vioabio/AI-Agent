## U1：补齐最后一层来源选择

精排后，`LocalGuideSearch.search`还会按文档去重，并为显式组队问题保留必要主题。原POST_RETRIEVAL_RERANK记录只能说明精排阶段，不能证明哪些资料最终返回给Agent。

新增第二条既有`retrieval.finished`事件：

```text
retrievalStage = FINAL_GUIDE_SELECTION
selectionPolicy = DOCUMENT_DEDUP_WITH_REQUIRED_TOPIC
selectedSources = [{documentId, chunkId, documentVersion}, ...]
```

最多记录实际返回的四项来源，不记录问题、正文或凭证。它不携带rerankState，避免将程序保留的主题误称为供应商精排结果。只在已启用精排且存在受控Run上下文时发出；默认关闭路径保持原状。

并发测试分别核对每个请求的精排状态与最终实际返回列表；另覆盖精排失败、answerTopK=1、组队主题保留，确保两阶段不混淆。

## 下一步开发：U6检索指标工具

新增`tools/campus/retrieval-metrics.mjs`与对应测试，按二值相关性计算每题及宏平均的Recall@k、MRR@k、nDCG@k。

输入示意（仅格式，不是质量标注）：

```json
{
  "schemaVersion": "retrieval-labels-v1",
  "datasetSha256": "填写实际数据集64位SHA256",
  "k": 4,
  "cases": [{
    "caseId": "开发集题号",
    "labelSource": "相关片段标注的来源/审核记录",
    "relevantChunkIds": ["已标注相关片段ID"],
    "rankedChunkIds": ["实际排序后的片段ID"]
  }]
}
```

```powershell
node --test tools/campus/retrieval-metrics.test.mjs
node tools/campus/retrieval-metrics.mjs artifacts/实际标注输入.json artifacts/新的指标报告.json
```

要求题号、候选和相关片段唯一；没有正相关标签时拒绝计算，不能把缺标签当作0分或满分。k限制1～50，输入文件最多2MB，报告拒绝覆盖。声明的数据集摘要只校验格式，输入文件另计算实际摘要；工具不替代冻结清单/人工或AI辅助语义复核。

指标仅代表给定标签下的片段排序，不代表回答正确、引用充分、因果收益或发布通过。输出固定`releaseDecision=NOT_EVALUATED`。本轮没有给未标注的真实题集生成“提升百分比”，没有执行封存题。
