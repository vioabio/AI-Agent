## S6-12隔离实例重启

启动器新增受控持久化数据目录复用，日志与数据目录分别记录。启动阶段使用独占文件锁和当前进程标记，重复打开仍被活动实例使用的数据目录会被拒绝。重启脚本核对PID、启动时间、构建目录和进程命令行中的数据路径，再停止指定测试进程。

验证使用同一账号、同一队伍、一条已完成对话与一条等待审批的修改任务。重启后使用原账号重新认证。

| 数据或状态 | 重启后的结果 |
| --- | --- |
| 账号 | 主体ID一致，原账号可重新登录 |
| 已完成对话 | 消息内容与记录标识一致 |
| 测试队伍 | 完整配置一致，等级保持51 |
| 待确认任务的历史 | 用户消息保留，未生成保存成功的回答 |
| 旧Run与旧审批 | 返回404，队伍未被旧审批修改 |
| 词法索引 | 指纹一致 |
| 向量缓存 | 两次均READY_REUSED，1024维、30片段，向量与元数据摘要一致 |

当前local模式的Run和审批对象使用内存存储。重启后旧任务不可继续确认，用户需重新发起预览；账号、消息、队伍及索引通过各自存储恢复。本次验证保留这一执行策略。
