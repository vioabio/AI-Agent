# U6 部分正文终止组合与MCP超时恢复

本轮补齐上一轮`partialAnswerObserved=false`留下的覆盖缺口，并开始项目MCP STDIO入口的客户端超时恢复验证。

## 部分正文终止

新增两组Spring HTTP测试上下文，分别开启、关闭Skills、上下文装配、回答卡片及领域追踪。每组覆盖HTTP取消、HTTP超时及真实浏览器断连恢复。

受控模型服务先发送“部分测试回答”，等待测试确认正文已进入Run事件或页面，再允许取消或等待Run期限。终态后释放上游尾部，检查追加发送尝试发生，随后回读原始事件与页面。

| 检查 | 实际结果 |
| --- | --- |
| 部分正文进入终止前游标 | 正文为“部分测试回答”，捕获游标早于终态 |
| HTTP取消 | 保留部分正文，唯一终态为`run.cancelled` |
| HTTP期限 | 保留部分正文，唯一终态为`run.timed_out` |
| 迟到上游输出 | 上游尝试发送“尾部”，已保存事件保持冻结 |
| 页面断连恢复 | 正文只显示一次，输入区恢复可用，显示正确终态 |
| 重复回放 | 正文、卡片与审批状态保持稳定 |
| 模型调用计数 | 每个Run仅一次规划调用和一次回答流请求 |

两组共4个HTTP Run、4个浏览器Run。新增6个Java测试全部通过，相关流式协议、租约及既有截断流回归34项通过。

### 受控范围

测试通过实际Spring Run入口、实际DeepSeek HTTP/SSE适配器及真实Chrome页面执行。模型服务使用本机HTTP替身，specialists、Embedding和精排在该组关闭。四个升级开关的实际诊断及前后运行组件摘要写入报告。

此记录用于验证传输、执行终态和事件回放。真实模型的回答质量、复杂多Agent取消与外部网络行为继续单独验收。

### 调试中修正的替身行为

首次六项检查因首个文本片段停留在Spring AI 1.0的usage前瞻缓冲中失败。替身原先等待终止后才发送下一片段，无法形成预期的“页面先显示部分正文”条件。

现于首个文本片段后发送无正文、无完成标记、无usage的排空片段，再等待控制闸门。接口终态与模型完成事件仍由真实业务代码决定。首次失败日志及目录保留，修正后在新目录重新执行通过。

## MCP客户端超时与恢复

新增`tools/campus/mcp-timeout-recovery.mjs`，调用项目实际`PokemonMcpServerMain`，复用已校验的公开PokéAPI缓存副本。

每轮为伤害计算请求设置1ms客户端期限。超时后发送取消通知及重复取消通知，随后在同一STDIO连接执行ping、工具发现和正常伤害计算。重复五轮后关闭连接。

| 检查 | 结果 |
| --- | --- |
| 客户端期限 | 5次均得到`MCP_REQUEST_TIMEOUT` |
| 取消后的工具发现 | 五轮工具列表一致 |
| 正常计算恢复 | 5次均返回13～16HP且条件校验为VERIFIED |
| 请求身份 | 超时请求ID递增，重复取消使用原ID |
| 协议帧 | 无效帧0，重复响应0 |
| 关闭 | 正常退出，强制终止为false |

本轮观察的是客户端期限与连接恢复。服务端逐项取消确认、网页Agent调用外部MCP后的取消传播和小时级压力继续待补。

## 可复现入口

使用隔离构建执行部分正文测试，保留浏览器依赖与Chrome。代码使用测试凭证及本机替身。

```powershell
.\mvnw.cmd -o -B -ntp `
  '-Dvio.build.directory=artifacts/<隔离构建目录>' `
  '-Dtest=PartialOutputEnabledRunHttpTest,PartialOutputDisabledRunHttpTest' test
```

每次启动生成新的`artifacts/u6-partial-enabled-*`和`artifacts/u6-partial-disabled-*`目录。目录内包含HTTP原始事件、浏览器日志、页面截图及`partial-browser.json`。准备好两组结果后执行以下校验。

```powershell
node tools/campus/upgrade-partial-combination-verify.mjs `
  artifacts/<开启组目录> artifacts/<关闭组目录> artifacts/<新的验证报告>.json
```

MCP探针接收独立客户端配置和公开缓存种子。配置中的Java命令、classpath及项目根目录须指向本机当前构建，入口固定为`com.vio.vioaiagent.mcp.PokemonMcpServerMain`。探针会将公开缓存复制到新的测试目录。

```powershell
node tools/campus/mcp-timeout-recovery.mjs `
  artifacts/<新的探针目录> artifacts/<独立客户端配置>.json artifacts/<公开缓存种子目录>
```
