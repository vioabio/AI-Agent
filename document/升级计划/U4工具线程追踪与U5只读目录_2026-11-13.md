## U4 工具工作线程

`AgentToolObservation` 在提交前捕获父 Observation，在真实工具回调所在的工作线程建立 `agent.tool.callback` 并打开作用域。接线位于网关的 `callWithTimeout`，保留已有授权、超时、重试与身份上下文处理顺序。

- 可形成 `agent.run.execute → agent.tool.callback → agent.model.call` 的关联。
- 工具名称为高基数关联属性，不记录输入、输出、用户身份或凭据。
- 原始异常仍交给治理网关，导出错误只记录 `TOOL_CALLBACK_FAILED`。
- 成功和异常均关闭作用域；同一工作线程复用后不能残留前一次 Run。
- 超时后若工具忽略中断，观测随真实回调结束；不因调用方已返回就把后台执行标为完成。已有未知副作用和租约策略不改变。

这是回调执行观测，不包含排队等待与授权检查；它们已有步骤计时，本轮没有宣称已纳入完整Span树。OTel白名单已增加该观测，默认导出仍关闭。Jaeger容器查看、全生命周期与开销对照仍待验收。

## U5-01 首批目录与参数边界

新增 `mcp/ReadOnlyMcpCatalog`，使用当前项目实际生成的 ToolCallback Schema 与既有能力卡。能力卡负责风险/角色检查，回调定义负责输入Schema，不能用能力卡中的默认空Schema代替真实参数。

首批仅列出：

| 工具 | 范围 |
| --- | --- |
| lookupPokemonReference | 公开图鉴参考，不证明玩家进度可获得性或赛事合法性 |
| checkPokemonBuild | 用户明确提供的培养字段核对，不读私有保存队伍 |
| calculateBattleDamage | 明确攻防双方和招式的本地确定性计算，不执行用户指定脚本 |

非白名单工具不会发布；选中工具缺失或有重复回调时拒绝构造目录。返回SDK工具描述时重新解析Schema，外部修改返回的Map不影响内部预检。

预检限制：UTF-8输入16KB、结果64KB、JSON深度16、禁止重复键与尾随JSON、根字段与必填项核对、数据版本固定为`pokeapi-reference-v1`；递归拒绝userId/runId/roles/principal/tokenBinding及脚本/命令等控制字段。错误只返回稳定类别，不回显原始输入；结果过大拒绝，不截断成成功结果。

**预检不是完整Schema验证或身份认证。** 后续执行适配器必须继续通过原治理网关做完整校验、授权、超时和结果审计；本轮没有直接调用领域工具的方法。

核对了项目依赖的 Java SDK 0.10.0，其协议常量为 `2024-11-05`，不是当前最新版协议声明。此阶段先按锁定版本构造工具描述，不顺便升级全项目MCP客户端依赖。[固定版本SDK源码](https://raw.githubusercontent.com/modelcontextprotocol/java-sdk/v0.10.0/mcp/src/main/java/io/modelcontextprotocol/spec/McpSchema.java)。
