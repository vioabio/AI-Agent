# 大厂 JD 调研与面试题库覆盖矩阵

查阅日期：2026-11-05。配套：[360 题面试全书](秋招双岗位全栈与AI应用开发面试全书_2026-11-05.md)。这是求职准备材料，不是职位推荐排序、薪资报告或公司真实面试原题。

## 1. 样本和证据标准

本轮检索字节跳动、美团、百度、腾讯、阿里巴巴、京东、小红书，以及华为、网易、小米的官方招聘入口。**7 家公司、10 个岗位有正文依据**，其中 4 个通过官方详情/公开接口读取（A），6 个通过官方页面的搜索索引读取（B）。后三家公司只作为入口或待核对线索，不计入完整岗位要求覆盖。

- **A：**官方详情或公开 JSON 接口读到职责、要求与招聘类型。字节接口返回 `data.job_post_detail`，不是 `data.job_post`。
- **B：**官方域名的搜索索引读到岗位内容；页面本身是动态壳，索引可能滞后，也可能只显示部分正文。只归纳实际读到的要求。
- **C：**只有官方入口/列表，或本轮访问受限；不根据公司名补造技术栈。
- 岗位发布时间、更新时间与本次查阅日期分别记录；未列时间就写未列，不把搜索抓取日期当发布日期。
- 页面可访问、接口标记在线或搜索有结果，都不保证尚有招聘名额。投递前重新核对职位状态、届别、学历、年限、城市和申请截止。
- 不采用第三方聚合站的面试题、薪资或未经核对的技术要求作为公司事实。JD 中“任一语言/框架”不改写成“必须全部精通”。

## 5. 为什么本题库还包含某些 JD 未逐字列出的内容？

HashMap、MVCC、CSRF、SSE 分帧等是从岗位中的“编程基础、数据库、接口、安全、流式交互”展开的基础练习，**不是声称招聘页逐字列出了这些问题**。WebGL、RSA/AES、ADB、SelectDB、FFmpeg、Whisper 等来自附件简历，需要能解释自己的表述；没有把它们列为全部公司统一门槛。

本次按用户工作涉及 Python / FastAPI 的补充，追加 [Q311](秋招双岗位全栈与AI应用开发面试全书_2026-11-05.md#q311)～[Q360](秋招双岗位全栈与AI应用开发面试全书_2026-11-05.md#q360)，共 50 题，并保留原 [Q001](秋招双岗位全栈与AI应用开发面试全书_2026-11-05.md#q001)～[Q310](秋招双岗位全栈与AI应用开发面试全书_2026-11-05.md#q310)。SQLAlchemy 2.0、HTTPX、TaskGroup、yield scope 等用于工程加深与示例验证，不推断为每个岗位的逐字要求，也不认定用户工作项目已使用全部组件。面试应核对实际版本、代码责任与证据。

算法/训练岗还可能要求数学、PyTorch、训练/对齐、竞赛或论文。应用岗应理解边界，但本书不把应用项目包装成训练研究资历；若投 J05/J10 等专项平台岗，需要进一步完成对应实验，不能只读题库。
