# VIO 宝可梦智能体：秋招简历写法

适用岗位：AI 应用开发工程师、Java / Vue 全栈开发工程师。描述依据当前仓库实现；个人职责需按实际参与情况填写。下文不补造性能提升、用户规模或线上运行数据。

## 简历推荐版

**VIO 宝可梦智能体｜领域 Agent 与全栈 AI 应用**

**技术栈：**Java 21、Spring Boot、Spring AI、Spring Security、DeepSeek、Vue 3、TypeScript、SSE、Tool Calling、SQLite、BM25 / Embedding、Node.js、@smogon/calc。

**项目介绍：**面向宝可梦资料查询、培养建议、道馆挑战与队伍搭配，构建可本地运行的全栈领域智能体。以 LLM 理解与工具编排为入口，结合结构化对话状态、检索增强生成（RAG）和确定性计算，在统一工作区完成“资料查询—队伍分析—计算核验—确认修改”。

- **Agent 编排与多轮状态：**基于 Spring AI 对接 DeepSeek，实现 ReAct 风格的 Tool Calling 循环；维护馆主目标、挑战阶段与队伍关联等结构化状态，并拆分资料检索、组队规划、伤害核验三个专用角色，以工具白名单和共享预算约束顺序协作。
- **知识增强与回答约束：**适配 PokéAPI 并实现本地缓存、版本与摘要校验；构建 SQLite / BM25 及可选 Embedding 混合检索链路，通过来源绑定与证据校验（Grounding）区分资料事实、策略建议和缺失信息，支持索引缓存与异常降级。
- **确定性计算与安全写入：**通过 Java 调用本地 Node.js `@smogon/calc` 引擎，校验计算参数、实际输入及伤害区间；队伍修改采用“读取—预览—确认—保存—回读”流程，引入人工确认（HITL）、账号归属校验与并发冲突检查。
- **全栈交互与运行治理：**使用 Vue 3 构建对话、图鉴与队伍统一工作区，实现 SSE 流式回答、图鉴联动和队伍 JSON 导入导出；通过 Run / Trace、事件游标重连、超时取消及模型／工具预算追踪与约束任务执行，异常断流不冒认为完整回答。
- **自动化与业务回归：**建立资料、数值、多轮状态、Embedding、授权及页面交互测试；最近后端回归执行 1,562 项，0 失败、0 错误、3 跳过；测试文档 68 项业务回归全部通过，保留失败样例、修复记录与验收边界。

## 全栈岗位调整建议

投递全栈岗位时，将“全栈交互与运行治理”放在第一条，再补充以下内容，按版面替换较长的 Agent 分工描述：

> 基于 Vue 3 与 Spring Boot 实现本机账号、历史会话、图鉴检索及队伍配置；通过 Spring Security、BCrypt、Session / CSRF 与数据归属检查保护私有数据，使用接口契约及 Playwright 验证消息编辑、图鉴联动、账号隔离和导入导出流程。

投递 AI 应用岗位时，保留推荐版排序，重点准备工具调用、结构化状态、RAG、数值证据和授权边界的源码讲解。

## 可在面试中展开的工程细节

| 主题 | 可以讲清的实现与取舍 |
| --- | --- |
| 多 Agent | 同一进程内、共享 ChatModel 的顺序协作；独立提示词、工具白名单与私有工作记录；主 Agent 负责最终回答和写操作确认 |
| RAG | BM25 提供关键词检索，Embedding 提供语义召回；索引绑定资料指纹与维度，错误配置或服务异常时明确降级；不宣称混合检索必然更优 |
| 对话状态 | 窗口历史之外保留结构化业务状态，避免序号指代、馆主切换和队伍追问退回目录；发生配置变更时重新读取和计算 |
| Grounding | 基于实际工具输入输出约束回答；未知物种保留目标并说明未找到，缺少计算条件时询问，固定属性倍率由程序计算 |
| HITL | 模型只能提出变更，用户确认后由程序执行；提交时核验身份与快照，保存后回读，避免越权与旧版本覆盖 |
| SSE | 正文与执行事件分开处理；游标用于事件重连；上游缺少完成标记时保留部分内容并明确失败，不重启生成冒充续传 |
| 执行可靠性 | 租约提交隔离（Lease Fencing）、不可变步骤输出（Immutable Artifacts）、幂等复用、摘要与加密 codec 已有实现；按仓储和配置启用，与默认 SQLite 本地模式区分 |
