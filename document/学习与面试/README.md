## 每日学习记录模板

```text
日期 / 用时：
源码提交 / profile / 数据版本：
今日问题与对应题号：
我能先给出的答案：
实际源码分支与工具事件：
动手输入 / 预期 / 实际：
失败原因与改进：
能否独立复现、修改、验证：
仍不确定或未验证的边界：
下次复习日期：
```

记录不包含Key、Cookie、真实账号密码、私有队伍或未脱敏日志。练习失败也应保留，能够解释一次真实失败通常比背诵更多名词更有价值。
