# 图鉴跳转、名称索引与在线环境参考

日期：2026-11-04。

## 1. 问题与修复

### 回答中的图鉴入口

原按钮仅发送 `facts` 分区事件，没有宝可梦目标，侧栏保留旧查询。

现在根据该条回答中明确出现的物种名称生成图鉴入口，传递全国编号，打开侧栏后立即执行查询。提到多只时提供独立按钮，历史回答也保留入口；不会从别的历史回答借用目标。“仙子伊布”中的“伊布”子串不单独生成入口。请求仍使用当前会话数据版本，不静默切换版本。

名称识别依赖物种索引，未明确提及名称的回答保留普通“查看图鉴”入口，不猜测“它”指向哪个对象。索引覆盖第九世代及以前1025个物种；不是全部地区形态索引，完整英文形态 slug 仍可手动查询。

### 名称与编号检索

新增 `/pokemon/reference/names`，从校验后的随包数据构建简体中文、繁体中文、英文 slug 和全国编号索引，不需要实时访问 PokéAPI。支持名称片段候选，选定完整名称后查询。中文和英文完整物种名转换为编号查询，兼容版本化事实接口。

主搜索框优先：输入新名称时，不再同时提交旧的高级编号条件，避免两个条件相互排斥。快速切换仍沿用 AbortController 与过期请求检查。

新增 `species.csv` 与来源、抓取时间、摘要元数据；原中文表保持不变。两张名称表只表达身份，不包含对战机制、当前强度或合法性。

## 2. 热门队伍与时效性

原因有两个：本地攻略不是最新赛事统计；通用 `searchWeb` 需要独立搜索凭据，DeepSeek Key 本身不会提供搜索能力。

新增 `lookupCompetitiveTrends`：

- 固定访问 `https://www.smogon.com/stats/`，发现最新已发布月份，再读取指定赛制使用率文件；不写死月份，不接受任意URL，不跟随跳转。
- 支持 `gen9ou`、`gen9doublesou`、`gen9monotype`，采用 `-0` 全部分段统计。
- 返回统计月份、赛制、样本对战数、使用率、抓取时间、原始来源链接。
- 缓存15分钟并保留原抓取时间；缓存过期后网络失败不会把旧结果标成最新。
- 通过现有治理网关执行，保留工具权限、Schema、超时、运行上下文和执行事件；程序选择标记为 `PROGRAM_CURRENT_META_SOURCE`。
- 对明确的环境查询发布工具核验结果，不让模型生成未经来源验证的胜率或完整阵容。该路径计为零次模型调用。

“当前有哪些热门队伍”先询问统计范围。当前页面的休闲赛制没有统一热门榜，不能自动当成 OU 或 VGC。下一条直接回复“OU单打”时，只承接紧邻的助手澄清消息，不从文档或任意旧对话中推导赛制。

**边界：**使用率属于月度单只数据，不是完整六人队伍榜、实时胜率，也不是游戏官方 VGC 统计。不能将使用率前六名拼成热门队伍。其他世代、游戏和规则不能混用。

## 3. 具体赛事队伍检索配置

已有通用搜索继续使用 SearchAPI，补充：

- 环境变量 `SEARCH_API_KEY` 接入公开配置；默认引擎 `google`，可通过 `SEARCH_API_ENGINE` 选择 `google`、`baidu`、`bing`。
- 完整响应限时14秒，治理超时16秒，避免原先5秒工具窗口频繁切断搜索；保留失败、空结果和配置缺失的区别。
- 返回来源日期（供应商提供时）、摘要与HTTP(S)链接；无效协议和含凭据链接不展示。
- 明确朱紫、VGC规则及时间后，优先检索 Limitless、Victory Road 的赛事入口；返回实际搜索摘要，不将摘要当成已读取完整队表的证据。
- 未配置搜索 Key 时明确提示未执行赛事检索及可用查阅入口。

在 IDEA 的 Environment variables 中配置搜索 Key 后重启后端即可。Key 留在本机，不写进本文、README 或 Git。

示例：

1. “当前有哪些热门队伍？” → 先确认赛制。
2. “当前朱紫 OU 单打有哪些热门队伍？” → 在线月度使用率、样本口径和原始来源。
3. “当前朱紫 VGC Regulation I 有哪些热门队伍？” → 配置搜索服务后返回对应赛事搜索摘要；仍需核对赛事日期与适用规则。
4. “不要联网，解释本地组队思路。” → 不触发新增在线预取。

开关：`VIO_TOOLS_SEARCH_ENABLED=false` 关闭通用搜索与在线统计；`VIO_TOOLS_TRENDS_ENABLED=false` 只关闭统计。
