## 新增可复现命令

从项目根目录执行，目标目录必须不存在：

```powershell
node tools/campus/local-smoke-workspace.mjs artifacts/campus/public-repro-new
node tools/campus/cold-npm-install.mjs artifacts/campus/public-repro-new frontend
node tools/campus/cold-npm-install.mjs artifacts/campus/public-repro-new engine
```

每个组件在`.cold-npm/<组件>/`保存计划、原始安装日志和报告。工具检查公开源清单、package/lock摘要、已有node_modules或缓存目录，并限制依赖来源为公开npm registry。未知组件、源文件改变、带凭据的地址、本地依赖链接、越界或符号链接逃逸均拒绝；失败不自动改用旧缓存，重新验证需使用新的公开工作目录。

调用本机Node运行npm-cli.js，不经过拼接shell命令；自动定位失败可显式追加`--npm-cli`指定本机npm CLI文件。Node/npm本身及操作系统仍为既有安装。npm HTTP请求重试设为0、单次fetch超时15秒；这不是整个安装任务的总时限，也没有执行依赖漏洞审计。

环境检查现在支持明确选择公开工作目录：

```powershell
node tools/campus/demo-readiness.mjs --root artifacts/campus/public-repro-new --bundle artifacts/demo-reference-v1 --java "$env:JAVA_HOME\bin\java.exe" --out artifacts/public-repro-readiness-new.json
```

资料包路径替换为实际已验证的公开包。报告仍只检查公开输入和版本元数据，不读取模型配置，不代表构建、服务或模型已经成功。资料准备与隔离启动参数见[复现手册](公开资料准备与演示复现手册_2026-10-30.md)。
