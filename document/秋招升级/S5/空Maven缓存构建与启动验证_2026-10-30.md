## 新增可复用准备工具

新增 `tools/campus/cold-maven-plan.mjs`，要求输入为经公开过滤的源码工作区；检查清单、pom、当前平台包装器及包装器配置摘要，拒绝路径逃逸、已有 target 或已有准备目录。不会清理旧仓库或覆盖旧实验。

```powershell
node tools/campus/local-smoke-workspace.mjs artifacts/campus/public-cold-new
node tools/campus/cold-maven-plan.mjs artifacts/campus/public-cold-new
```

工具创建 `.cold-maven/repository`、公开 Central settings、空 global settings 和计划文件。**生成计划不执行构建，也不表示构建通过。**在正确配置 JDK 后，按计划逐个参数执行：

```powershell
$plan = Get-Content artifacts/campus/public-cold-new/.cold-maven/plan.json -Raw | ConvertFrom-Json
Push-Location $plan.command.cwd
try {
    $buildArgs = @($plan.command.args)
    & $plan.command.file @buildArgs
    if ($LASTEXITCODE -ne 0) { throw '冷构建失败，请保留日志与依赖仓库' }
} finally { Pop-Location }
```

JDK 和 Maven 包装器下载/安装不属于此工具职责。不要在失败后复用普通依赖缓存并声称冷构建成功。

实际在线构建早于准备工具完成，采用同等显式参数；两者分开留证：[实际准备记录](evidence/cold-maven-v1/preparation-v1.json)与[工具仅生成的计划](evidence/cold-maven-v1/helper-plan-only.json)。后者属于另一个新工作区，`commandExecuted=false`，不能当作已执行命令的证据。工具新增 5 项测试，覆盖空仓库、重复准备、旧构建、篡改和路径逃逸。
