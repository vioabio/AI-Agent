## 复制和身份约束

新增`tools/campus/local-smoke-workspace.mjs`，从Git枚举的当前公开文件中按允许范围选择构建输入，过滤私有配置及运行产物，再复制到artifacts内全新目录。原私有配置在筛选阶段即被排除，未读取、复制或修改。符号链接越界、目录越界、已有目标和缺少必要公开文件均拒绝。

源清单逐文件记录摘要，复制后校验；本批归档时再次核对工作树与新目录的672个输入一致。JAR列表确认公开示例配置存在，未含被排除的应用profile、MCP配置或SQLite文件。此检查针对已列出的路径与规则，不是通用密钥检测器。

## 首轮失败与修复

首次探针在注销后直接再次登录，收到403。原探针没有刷新注销后失效的CSRF状态；前端已有会话刷新流程，本批未修改应用认证代码。修正探针先GET会话以获取新CSRF，再登录，第二轮全部通过。首轮失败记录与修正后记录分别保存，没有把403伪装为成功，也没有调整后端安全策略。

探针生成的账号、密码、恢复码、Cookie仅存在于测试进程内存或隔离服务自身数据库，不写入归档探针报告。临时SQLite不提交到Git。

## 复现构建

从项目根目录运行，目标目录必须不存在：

```powershell
node tools/campus/local-smoke-workspace.mjs artifacts/campus/local-smoke/workspace-new
```

随后在新目录使用已配置的Java 21执行：

```powershell
.\mvnw.cmd -o "-Dmaven.test.skip=true" package
npm --prefix vio-ai-agent-frontend ci --offline
npm --prefix vio-ai-agent-frontend run build
npm --prefix tools/pokemon-engine ci --offline
```

缓存缺失应明确记录，不能把联网补齐后说成空缓存离线安装成功。启动需显式指定公开配置、无效Key和隔离数据路径，禁止回退读取原工作区私有配置。模型功能需由用户在本机另行配置真实Key，该步骤不在本次无Key冒烟范围。

服务就绪后，在原项目根目录运行：

```powershell
node tools/campus/local-smoke-probe.mjs http://127.0.0.1:18259/api artifacts/campus/local-smoke/probe-new.json
```

探针只允许18259端口和全新输出文件，不自动启动服务，不调用模型或抓取资料。后台监听端口及进程归属须由运行者在启动前确认，完成后仅停止自有前台进程。
