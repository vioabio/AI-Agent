# 发送前检查

在尚未安装和运行的干净交接目录执行：

node tools/campus/verify-local-handoff.mjs

cleanPackage=true且退出0才通过本项检查。依赖、target、dist、账号数据库、私有配置和未登记文件会导致拒绝；安装运行后的目录通常不再适合分发。工具不删除文件，请从原项目重新生成新目录，不要清理掉需要保留的数据。报告请重定向到交接目录之外，否则报告本身也会成为未登记文件。

清单未签名，自带校验器也不构成外部信任根；请用可信仓库版本校验不可信来源的目录。通过不代表真实性、已安装、已启动或模型问答通过。旧v1格式交接包需要重新生成。
