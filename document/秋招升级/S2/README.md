# S2：真实评测基础与首轮回归

2026-10-23 已实现固定种子集、分组切分、真实 HTTP 采集、重复运行、不可覆盖的观测记录、案例级报告、绑定答案的人工复核模板及复算命令。当前为 **S2 第一批交付，整体仍在进行中**。

数据入口：[36 条种子集与操作步骤](../../../evaluation/campus/s2/README.md)、[标注规范](../../../evaluation/campus/s2/annotation.md)、[验证记录](验证记录_2026-10-23.md)。

本轮新增的实际能力：

- 六类任务统一记录输入、运行身份、版本、答案、工具结果、状态、回读和耗时。
- 36 条问题按 20 组固定拆分为 14 条开发集与 22 条保留集，相似问法不跨切分。
- 工具完成、结构检查、人类语义核对分别统计；原分母保留所有计划轮次和失败。
- 队伍预览检查具体字段与存储不变，之后取消；不自动代替用户点击确认。
- 跨账号 HTTP 探针与真实模型回答分别留证；计算参考核对固定引擎数值，但模型计算输入仍未完全证明。
- 报告中 Token、成本、未接通的检索指标明确为 unknown/未测量。
- CI 增加种子集与评测器契约检查，只运行确定性测试，不调用真实模型；尚未在 GitHub 远端执行本轮配置。

针对实测暴露的通用攻略过度追问，提示词明确攻略可按通用主题检索，不必先给具体物种；运行身份接口与实际 Agent 共用提示词版本常量。它是行为提示，不是强制语义保证，效果以重复运行和来源核对为准。

后续[来源与配置回答修复](来源与配置回答修复_2026-10-23.md)进一步接入原文节选、保存快照事实展示与字段保护，修复已复现的引用外扩、hardy误写固执、种族值标成50级数值的问题；保留初次错误答案作为回归依据。专项回归不替代完整人工质量验收。

S1 同时增加了受控 Run→真实工作流→SQLite/事件/历史的读取失败和计算失败集成回归，断言失败终态唯一、没有预览、没有成功回答和存储变化。该测试使用受控执行器，不能冒充真实模型、真实网络故障或完整浏览器端到端覆盖。

剩余交付顺序：

1. 人工核对首版题目、验收项、原始回答及引用，并补充真实问题至计划 100 条。
2. 增加模型实际工具入参的安全可审查证据，解决“工具成功但条件是否一致未知”。
3. 补齐更多异常 HTTP/浏览器全链测试和确认保存任务评测，保持本地权限与审批边界。
4. 固定模型参数后增加纯模型对照；S3 完成后执行同题检索＋工具对照。
5. S3 接通检索排名与片段标注；S4 接通真实 usage/成本，再报告相关指标。

未将种子集、结构测试或少量重复运行包装为完整准确率，不改变 v1.0/v1.1 门禁或自动恢复策略。
