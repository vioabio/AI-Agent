# S4 第六批：对话偏好与长期约束快照

本批增加用户主动保存的会话级偏好：回答详略、培养成本、建议避开传说宝可梦及补充要求。偏好独立于最近问答窗口保存；历史被裁剪后仍进入当前请求。网页顶部点击“对话偏好”设置，当前会话保存后生效，新对话单独设置。

这是显式偏好记忆，不自动从聊天、模型回答、攻略或工具输出推断用户事实。保证的是保存、隔离、版本和请求回填，不保证模型每条建议都符合条件；对战机制、当前队伍和合法性仍需真实资料及工具验证。

## 保存与覆盖规则

| 字段 | 可选值 / 范围 | 含义 |
| --- | --- | --- |
| responseStyle | STANDARD / CONCISE / DETAILED | 适中、简洁重点、详细解释 |
| trainingBudget | UNRESTRICTED / LOW | 不限制或优先低成本培养 |
| avoidLegendary | boolean | 建议避开传说宝可梦，不是合法性判定 |
| notes | 最多800个UTF-16字符 | 用户主动填写的补充条件；允许换行，拒绝其他控制字符 |
| revision | 非负安全整数 | 保存时提交当前修订，成功后递增 |

设置按现有认证主体和 conversationId 隔离。客户端不能指定其他账号归属，权限仍由后端认证上下文决定。未知或其他账号会话的读取为404；首次保存可为当前账号建立空会话，再原子写入偏好。已存在的其他账号会话不能被覆盖。内存仓储的会话保存也补齐了同ID归属检查。

保存使用比较并交换（CAS）：初次revision=0，之后提交上次读取的revision。旧页面保存得到409，保留草稿并提示先重新读取，不自动覆盖新设置。恢复默认只重置偏好内容，仍使用当前修订保存；不是把修订归零。界面不会在未确认的网络结果上显示“已保存”。

偏好只作为当前账号输入。当前问题的具体条件优先，Run的版本/赛制、真实队伍状态和工具授权继续沿用原规则；偏好不能批准写队伍、终端或其他工具操作。

## 每次任务固定快照

```text
用户点击保存 → 当前会话设置（CAS）
创建Run → 读取偏好 → 保存到该Run的用户消息metadata → 初始checkpoint
执行/审批后续尝试 → 读取同一Run快照 → 作为当前用户请求的一部分回填
模型上下文预算 → 可裁剪旧问答，不能单独裁掉当前偏好
成功回答 → metadata保存该Run相同偏好快照
```

`conversation-constraints-v1`标记DEFAULT或USER_CONFIRMED来源。模型不会修改这份状态，也不会把猜测写回数据库。快照位于当前用户请求，未提升为system消息；补充文字由JSON编码处理。它与当前问题一起计入现有上下文预算，超限沿用安全停止机制，不静默丢掉偏好。

用户在另一页面更新设置时，正在排队、执行或等待审批的Run继续使用创建时快照，之后的新Run读取新修订。旧历史/旧Run缺少偏好时采用明确默认值，不从当前最新设置反推过去；存在但损坏的快照会拒绝继续执行。

有保存修订时，偏好快照加入checkpoint及步骤artifact的contextHash，绑定修订和内容。用户消息先于初始checkpoint写入，避免初始hash使用默认值、之后却使用新设置。revision=0的旧默认上下文保持原hash兼容。原租约、副作用UNKNOWN和禁止自动重放execute-answer/commit-answer的策略未放宽。

## 本地数据与接口

本地沿用`.local-data/history.sqlite`：

- `local_conversation_constraints`保存当前设置、修订和JSON，引用local_conversation；删除本地会话时级联清理。
- 用户消息和成功回答的metadata保存各自Run使用的快照，便于核对旧回答的输入条件。
- 仓储重开和独立连接并发保存已验证；存储错误不会被当成空偏好静默忽略。

偏好会发送给当前配置的模型；本地历史和既有提示词诊断日志仍按项目现有配置处理。本批没有增加跨设备同步。

生产/演示JDBC实现新增Flyway `V31__conversation_constraints.sql`，使用同样的原子CAS和账号条件，软删除会话不可读写。SQL及迁移语句由SQLite兼容测试验证，**尚未完成真实PostgreSQL迁移和多实例集成验收**。

接口沿用同源Cookie、CSRF及`/chat/**`认证规则：

```http
GET /api/chat/conversations/{id}/constraints
PUT /api/chat/conversations/{id}/constraints
Content-Type: application/json

{
  "revision": 0,
  "responseStyle": "CONCISE",
  "trainingBudget": "LOW",
  "avoidLegendary": true,
  "notes": "请面向新手，优先解释水属性成员的培养。"
}
```

成功返回新revision和规范化字段；400表示字段无效，404表示会话不可访问，409表示修订已变化。正文、密码和认证信息不会放进URL。当前网页任务执行中禁用偏好入口；其他页面的合法设置更新仍可完成，只作用于后续任务。
