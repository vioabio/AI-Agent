# S3：本地知识检索

当前默认已接入[第二批12篇笔记与来源登记](来源与语料扩充_2026-10-23.md)。以下保留首批4篇基线的设计说明；第二批使用独立资料和评测版本，原基线不删除。

后续[S4真实回归](../S4/验证记录_2026-10-23.md)发现一次重复检索被拒绝后回退为资料不足提示，未通过引用验收。此前通过记录继续保留，这项可用性缺口仍待修复，不能据小样本宣称攻略问答始终成功。

本批把原有攻略从启动时扫描正文，升级为 **SQLite 持久化倒排索引 + BM25 词法排序 + 可定位的原文片段**。无需额外服务器或 embedding Key。仍只有原有 4 篇项目原创笔记，S3 整体尚未完成。

## 实际接线

```text
pokemon-guides/index.json（受审查的本地文件）
  → 有界解析、来源/日期/范围校验、同范围正文去重
  → 按段落/句子切片（最多400 Unicode码点，保留原文偏移）
  → SQLite 文档、chunk、倒排词项、索引身份
  → KnowledgeRetriever 接口的本地适配器
  → 范围与有效期过滤 → BM25 词法召回
  → searchPokemonGuides / HTTP 检索
  → 原文、片段定位校验 → 攻略正文按段发送
```

复用 `KnowledgeRetrievalQuery`、`RetrievedKnowledgeChunk`、`KnowledgeChunkView` 与 `DocumentChunk`，本地实现由 `LocalGuideSearch` 显式持有，不注册第二个未限定的 Spring 检索器 Bean。已有版本化知识门面继续使用原检索器，未改其发布、恢复或权限门禁。

中文使用相邻汉字二元词，英文使用单词；索引保存词频，标题权重4、关键词权重1、正文权重1，使用 BM25（k1=1.2，b=0.75）排序，稳定 chunkId 决定同分次序。分数只用于排序，不能解释为答案置信度。没有向量、语义召回、重排模型或模型调用费用。

## 存储与更新

默认数据库为 `.local-data/guides.sqlite`，可通过 `VIO_LOCAL_GUIDES_PATH` 或 `vio.local-guides.path` 覆盖。原文仍以 JSON 文件为准，通过 `VIO_LOCAL_GUIDES_LOCATION` 指定导入文件；本批按启动时导入，不提供任意网页抓取或聊天内改写知识库。

启动时校验原文元数据、全部派生行与算法版本；一致时复用原索引和构建时间。变更时在一个 SQLite 事务内替换，写入失败回滚。不同进程的启动写入被串行处理；若另一进程后来切换到不同索引，旧进程查询会拒绝并要求重启，避免混用版本。该实现面向小规模本地库，不宣称多实例生产性能。

稳定标识关联文档身份、完整元数据版本、原文偏移与内容摘要。原文或作者/日期/范围变动会使旧 chunk 链接失效。索引身份用于本地复现，不冒充原 v1 发布审核血缘。正文不展示这些长摘要，只显示“原文位置：第 N 个片段”。

## 导入范围与接口

保留原 `schemaVersion:1` 与8字段资料格式；新增可选字段 `language`、`battleFormatId`、`rulesetVersionId`、`validUntil`。旧格式明确按原本地场景解释为 `zh-CN / casual-singles / casual-v1`，不是从正文推断。当前导入只接受朱紫及上述已登记范围；非空的未知范围在加载时拒绝。

每篇保留标题、作者、更新日期、来源链接和完整原文；`validUntil` 为可选 ISO 日期，截止当天有效，过期后检索和片段定位均不可用。未指定有效期只表示通用笔记未设截止日，不能据此证明实时性。外部 URL 是原创说明引用的接口项目，不表示外部作者背书整篇内容。外部文章的授权、分类和更完整来源元数据待后续补齐。

原接口 `GET /api/pokemon/guides` 和工具名保持兼容，每次最多返回4个不同来源，新增 `citation`。工具所用语言、赛制、规则来自当前认证 Run，模型只提供问题和游戏版本；范围不符返回空结果，不回退到其他版本。

供验证和定位的接口：

| 接口 | 用途 |
| --- | --- |
| `GET /api/pokemon/guides/index` | 算法、索引身份、文档/片段数量、构建时间与本次启动是否复用 |
| `GET /api/pokemon/guides/retrieve?query=努力值&gameReleaseId=pokemon-scarlet-violet` | 最多5个真实 chunk，默认按本地中文休闲单打范围检索 |
| `GET /api/pokemon/guides/chunks/{chunkId}` | 回读原文和片段；不存在、过期或新索引已移除时404 |

以上走已有认证规则。`language / battleFormatId / rulesetVersionId` 可用于 HTTP 范围筛选。攻略服务参数无效返回400，避免误报系统故障。

## 引用边界

回答先校验实际工具结果的原文摘要、元数据版本、chunkId、序号、偏移和逐字文本，再展示对应原文。空结果、截断、篡改或过期来源不生成带引用的攻略结论。资料中的 HTML、Markdown 和命令句按引用文字处理，不执行为应用操作。

该实现仍采用保守的原文节选，不把模型自由生成的机制解释自动挂到引用下面。注入转义和来源篡改有确定性回归；不据此宣称抵御所有模型提示注入或知识投毒。
