## 证据与复现

仓库归档：[检索与重启](evidence/retrieval-validation.json)、[模型及流式回归](evidence/model-regression.json)、[本轮验证汇总](evidence/verification-summary.json)。紧凑归档保留原始文件摘要，不含认证凭据；完整请求结果和事件位于Git忽略的 `artifacts/campus/s3/`，导入、算法和指标口径见[阶段说明](README.md)与[评测说明](../../../evaluation/campus/s3/README.md)。

启动独立本地验证服务（先设置JAVA_HOME并保证18132空闲）：

```powershell
.\mvnw.cmd -o spring-boot:run '-Dspring-boot.run.arguments=--server.port=18132 --vio.run.answer-streaming-enabled=true --vio.local-accounts.path=./artifacts/campus/s3/my-runtime/accounts.sqlite --vio.local-history.path=./artifacts/campus/s3/my-runtime/history.sqlite --vio.local-teams.path=./artifacts/campus/s3/my-runtime/teams.sqlite --vio.local-guides.path=./artifacts/campus/s3/my-runtime/guides.sqlite'
```

在另一个终端执行，每次使用新输出目录：

```powershell
node tools/campus/s3-retrieval.mjs http://127.0.0.1:18132/api artifacts/campus/s3/my-retrieval
node tools/campus/s2-evaluate.mjs run --base-url http://127.0.0.1:18132/api --case S2-GUIDES-01,S2-CLARIFICATION-01,S2-TEAM-01 --repetitions 1 --output artifacts/campus/s3/my-model
node tools/campus/s2-quality-regression.mjs artifacts/campus/s3/my-model/observations.json artifacts/campus/s3/my-checked
```

再次启动时沿用同一索引数据库验证复用，用新的结果目录保留重启证据。旧用户服务需自行正常重启后才加载新增实现；本批没有提交、推送或部署。
