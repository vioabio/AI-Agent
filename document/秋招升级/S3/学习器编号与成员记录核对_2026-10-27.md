# 学习器编号与成员记录核对

在上一批学习方式和等级提示基础上，本批补充可实际查询的朱／紫学习器编号。先核对本成员快照中的machine途径，再核对固定招式、学习器、道具三份公开资料，不从模型记忆填编号。

## 来源与范围

固定资料来自[PokéAPI的Machines接口](https://pokeapi.co/docs/v2#machines)。机器资源ID与游戏中的TM编号分别保存：前者定位接口资源，后者从同版本道具标识解析，并以三位数字展示。未混用其他版本的同名TM。

| 招式 | 本批显示 | 学习器资源ID |
| --- | --- | --- |
| 水之波动 water-pulse | TM011 | 1826 |
| 冰冻光束 ice-beam | TM135 | 1950 |
| 守住 protect | TM007 | 1822 |
| 水炮 hydro-pump | TM142 | 1957 |

每条保留move、machine、item三个原始公开响应及摘要。校验招式到学习器的朱紫关联、学习器里的招式/道具/版本、道具反向关联；目录身份固定在代码中，来源损坏或错配拒绝加载。应用不执行上游脚本，不在运行时跟随上游URL。目录文本按LF规范化，原始响应按内容摘要核对；摘要是内容身份，不是上游签名。

本批仅4项编号，不代表全部TM目录。成员学习快照取自已有公开缓存，编号资料另于2026-10-27取得，日期不同，不宣称同一游戏补丁的原子快照或实时赛规。它们仍来自同一PokéAPI，不作为第二独立机制来源。地点、制作材料、取得/使用条件、遗传与回忆操作、四招共同可得和赛事合法性均未验证。

首次直连抓取在取得一项后超时，保留已有文件，按本机单独的公开资料网络配置补齐其余来源；未读取私有模型配置。最终12份来源完整核对，不把部分下载描述成完成。

## 使用与接线

队伍配置中点击“检查当前配招”，在记录了学习器途径的招式下点击“查看学习器编号”。成功时展示短编号及三个来源链接；不会保存或修改队伍。请求取消、组件卸载、配置变化后清除旧结果；返回的成员、招式、版本、快照摘要、学习投影和条目必须与当前报告一致，旧快照或迟到响应不能恢复旧编号。浏览器检查用于防止串用结果，不宣称独立密码学认证。

```text
GET /api/pokemon/reference/machines/{pokemonId}/{moveSlug}
    ?dataReleaseId=pokeapi-reference-v1&gameReleaseId=pokemon-scarlet-violet

lookupPokemonMachine(pokemonId, moveSlug, dataReleaseId, gameReleaseId)
```

新只读工具仅在本地参考启用时注册，沿用原角色、Run所有者和版本检查。评测仅READ_ONLY_TOOLS加入它，纯模型与仅攻略组不增加能力；原保存审批和恢复门禁不变。明确的结构化配招请求若还要求学习器编号，不再由只提供配招报告的程序路径提前结束，继续由既有Agent工具流程处理。

`MachineReferenceFacts`绑定成员学习记录与固定目录，并将报告和实际工具参数关联；完成事件附`machine-output-evidence-v1`，记录输入与输出身份。Agent只展示核对后的编号及来源，失败不使用模型猜测或编造获取操作。模拟供应商回归验证SDK、治理和正文接线；这不是实际供应商的工具选择成功率。

| 状态 | 用户可见含义 |
| --- | --- |
| MATCHED | 本成员记录machine途径，固定三方资料匹配，展示编号 |
| MEMBER_MACHINE_NOT_RECORDED | 该成员快照未记录学习器途径，不能断言不能学习 |
| NOT_CATALOGUED | 成员有记录，但本批4项编号未收录 |
| REFERENCE_UNAVAILABLE | 成员记录未读取成功，本次不提供编号 |

格式、版本错误返回400；有效的缺失状态保留200并明确原因，避免误报为“非法配招”。原图鉴客户端、队伍存储、伤害桥接、旧资料及正式题集保持原样。
