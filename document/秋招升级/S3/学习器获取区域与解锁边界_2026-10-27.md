# 学习器获取区域与解锁边界

本批接续配方参考，提供两份社区资料共同列出的大区域线索。队伍配置中先“检查当前配招”，查询匹配的学习器编号后，点击“查看获取区域”。明确的“学习器获取/位置/地点/解锁”问法会加入原编号核对规划提示，编号MATCHED后由程序补区域参考。提示要求成员不明时补问，本轮未测试真实模型的工具选择或澄清成功率。

## 当前可用内容

| 招式 | 本批共同区域线索 |
| --- | --- |
| 守住 TM007 | South Province (Area One)、South Province (Area Four) |
| 水之波动 TM011 | Socarrat Trail |
| 水炮 TM142 | Casseroya Lake |
| 冰冻光束 TM135 | 一份资料缺少地点行，保留资料不足提示，不发布区域结论 |

来源为[Pokémon Database朱紫TM表](https://pokemondb.net/scarlet-violet/tms)和[Serebii朱紫TM表](https://www.serebii.net/scarletviolet/tm.shtml)，复用2026-10-27已保存的两份公开文本快照，不覆盖上一批来源或观察。区域名称保留英文，界面展示两份来源及核对日期。

两份原地点列表并不完全一致。本批只按明确登记的四组区域页面路径提取交集，不声称完整列表相等、完整覆盖或游戏内验证。例如Pokémon Database的整个Great Crater条目与Serebii的Area Zero条目没有自动合并，水炮本批仅展示双方明确列出的Casseroya Lake。区域线索不包含精确坐标、NPC条件、路线或剧情门槛。

两站数据是否独立尚未确认，交集只表示本批固定资料的对应关系，仍待独立人工及游戏内核验。

单一来源中的剧情解锁文字只保留在原始观察，不进入接口和正文。所有结果的`unlockStatus`均为`NOT_CROSS_CHECKED`；缺少解锁行也不解释为默认解锁。精确解锁条件与学习操作继续待办。

水之波动的配方仍为材料拼写差异状态，但其共同区域线索可单独提供。两类资料分别判定，不以地点交集解决材料差异，不以材料差异删除已有区域依据。原配方、编号、官方通用制作说明及其历史证据均保持原样。

## 实现

`tools/campus/machine-acquisition.mjs`提取指定TM行的原区域路径、原名称、单一来源的解锁文字、片段位置及摘要，生成`pokemon-machines/acquisition-catalog-v1.json`。来源缺失、重复目标行、错编号/招式或超大输入拒绝处理；写目录必须使用显式build与新目标路径，verify只核对重建结果和Java固定摘要。

`MachineAcquisitionCatalog`有界读取并校验目录身份，将四项招式和编号关联到原固定编号目录。损坏、缺失或过大资源拒绝加载；CRLF按LF规范化。对外返回不可变区域与来源列表，不跟随来源URL或执行上游脚本。完整HTML继续只保留在忽略的artifacts中，摘要标识本地UTF-8快照，不代表上游签名。

接口：

```text
GET /api/pokemon/reference/machines/acquisition/{moveSlug}
    ?gameReleaseId=pokemon-scarlet-violet
```

沿用本地参考启用条件、profile和既有认证链，不新增工具权限，不读取成员缓存、背包或玩家剧情，不写队伍。有效但未收录的招式返回`NOT_CATALOGUED`，错误版本/slug返回400。

| 状态 | 含义 |
| --- | --- |
| COMMON_REGION_REFERENCE | 原列表存在明确共同大区域，展示有限交集 |
| SOURCE_INCOMPLETE | 至少一份来源没有地点行，不能据此断言没有获取地点 |
| NO_COMMON_REGION | 两份非空列表没有登记的共同区域，不等于无法获取 |
| NOT_CATALOGUED | 本批没有该招式观察 |

前端按招式、编号、游戏、目录身份和固定来源核对响应，区域ID与原英文名须属于登记映射。未核对状态不得夹带区域或“已解锁”声明。支持按需展开/收起、失败重试、请求取消及序号隔离；修改配置或卸载后清除旧结果，迟到响应不恢复旧信息。所有文字按纯文本渲染，不展示长摘要。此为应用契约检查，不构成独立事实认证。

Agent继续调用原`lookupPokemonMachine`治理工具；编号核对成功后，程序从固定目录补充区域。未取得有效成员/招式证明时不借区域知识绕过检查，单来源的剧情条件不用于回答。该补充来自本地固定目录，不是新增模型推理或新增工具结果；原编号报告schema和工具结果证明保持兼容，回答版本与运行时目录身份单列。
