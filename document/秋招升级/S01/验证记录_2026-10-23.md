## 使用新版本

在自己的终端停止旧前端，运行 `npm --prefix vio-ai-agent-frontend ci`，再启动 `npm --prefix vio-ai-agent-frontend run dev`。重启后端以加载新工具和证据检查。API Key 继续留在本机配置/环境，不需要发到聊天中。

如果要实测 DeepSeek，沿用主 README 的 `local,deepseek` 启动方式，并在本机配置 `DEEPSEEK_API_KEY`；登录后查看运行诊断接口确认配置 ID，再执行真实固定任务。不要把启动成功或配置 ID 等同于模型建议质量通过。

阶段边界：本轮交付 S0.1 的可用证据约束与依赖修复。S1 队伍确认写入、S2 正式质量评测及后续阶段均未因此标记完成。
