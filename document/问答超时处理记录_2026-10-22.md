## 现象与判断

用户报告 Run `run-f0444f05-f589-4b2c-a0cb-bb58b7c800dc`（trace `7f7cac55`）中五次工具调用均完成，但任务最终显示 `deadline_exceeded`。

该错误表示 Run 总截止时间到达，不表示某一个工具执行超时。HTTP 创建 Run 默认总预算为 120 秒，包含模型决策、工具执行和回答生成。当前工作区没有找到该 Run 的运行日志，因此尚不能确定此次模型各轮请求的实际耗时，也没有复现真实供应商请求。

## 本次修改

- 调整 VioManus 提示：证据足够后直接回答，直接回答会自动结束任务，不再要求额外调用结束工具；避免无必要地同时读取完整属性表和单个克制关系。
- 保留结束工具兼容性：若本轮仅调用 `doTerminate`，且已同时返回非空回答，直接复用该轮回答，流式内容不重复发送。若同轮还有其他工具，或结束轮没有回答，仍在工具执行后生成总结，避免把执行前的说明当作最终结论。
- 超时提示改为中文，已有增量内容继续保留并提示回答尚未完成；原始错误码仍保存在事件数据中，便于排查。
- 保持现有 Run 截止时间、取消、审批、租约及失败终态约束，不把超时任务标记为成功，不自动重放工具。
