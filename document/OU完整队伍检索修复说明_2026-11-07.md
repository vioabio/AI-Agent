# OU 完整队伍检索修复

## 缺陷与修改

原 `CompetitiveTrendsRequest` 将“热门队伍”和“使用率”一起交给 `lookupCompetitiveTrends`，`ToolCallAgent` 随后直接生成单只使用率表并结束回答。模型没有继续读取完整队表的机会。

现在询问队伍、阵容及详细配置时选择 `lookupCompetitiveTeams`；明确询问使用率或排名时保留统计工具。队伍工具关闭、权限失败或来源不可达时，不再回退到使用率表。

## 数据与显示

- 目前完整来源只支持 **gen9ou**，没有把 VGC、Doubles OU 或休闲单打当作 OU。
- 仅从 Smogon SV OU 样例主帖的首条正文提取 PokePaste 链接，不读取历史回复作为当前样例。
- 并发读取链接对应的 JSON 配置，排除纯说明页、缺少六人、缺少四招及不识别的指令行。
- 返回最多三支实际取得的完整样例，保留作者、配置链接、抓取时间及可解析的原帖更新时间。
- 原始 Showdown 配置展示持有物、特性、性格、EV/IV、四招及太晶信息；默认值另行说明，未提供太晶属性不编造。
- 这是“公开样例队伍”，不宣称实时热门排名、胜率或当前合法性。不会自动写入用户队伍。
- 工具经过现有角色、网络治理和审计链路；仅访问固定 Smogon 主帖及从该主帖提取的合法 PokePaste ID，不接受任意 URL。

## 实际网络限制

本机联网测试中 Smogon 返回 HTTP 200，但正文是 `Checking your browser` 验证页；PokePaste JSON 可以读取。主帖链接中的 description 页确实只有说明文字，不能当作六人配置。

程序会识别上述情况并说明完整来源未取得，给出主帖入口，**不会把 mock 测试中的队伍冒充线上抓取结果**。本次成功链路由可控测试源验证；不能宣称当前网络下已成功取得真实最新六人样例。

后续如需提高可用性，应增加经核验、带版本和时间戳的样例索引镜像或授权数据源；离线快照必须标注快照时间和是否已过期，不能冒充实时热门结果。不要关闭来源校验、抓取历史回复凑数，或使用搜索摘要补造配置。

## 验证入口

`CompetitiveTeamsToolTest` 验证完整配置、缓存、错误来源和描述页拒绝；`CompetitiveTrendsRequestTest` 验证意图区分；`CompetitiveTrendsAgentTest` 验证原问题的完整回答、流式发布、权限及失败不回退使用率。后端修改生效需要重新编译并重启实际服务。

本轮整体后端回归：1421 次执行，0 failures、0 errors、3 skipped。实际运行程序已更新为包含新工具的打包产物；本机网络的 Smogon 主帖拦截仍是外部限制，并未因测试通过而消失。
