# 回答正文与资料提问修复

## 用户反馈

雪妖女介绍任务（Run `run-3c20f00b-9aef-41c0-a98f-b0789fadbff1`）只展示了英文的“已有足够资料，接下来回答”，却标记为已完成。资料卡生成的问题还带有完整 JSON、校验值、内部 ID。

## 原因与修改

1. 旧链路把模型工具决策阶段的 `content` 直接发送到回答流；无工具调用的非空文本也直接作为答案。决策文字可能只是规划，不能等同于完整答复。
2. 工具决策改为私有请求，正文不进入用户回答流；工具结束或决策无需继续执行时，进入独立的最终回答生成阶段。最终阶段不注册工具，流式模式只发布最终阶段的增量，同步模式同样单独生成最终回答。
3. 最终提示遵循 Run 语言，默认简体中文；要求直接回答，不输出计划、工具故障猜测、JSON、checksum、UUID 或内部版本标识。保留有用的对战数值、事实与建议的区分，以及来源不足说明。这是提示约束，不是模型质量保证。
4. 资料、队伍、攻略和伤害按钮使用中文可读提问，不再直接拼完整 JSON。仍通过独立的上下文字段传递数据/规则版本，未删除版本校验。
5. 对准确匹配旧版资料提问格式的用户消息，界面显示、复制及编辑时转换为可读问题。普通消息不进行通用 JSON 过滤，历史数据库原文不被改写。
6. 资料版本与回答限制默认折叠，Run、trace 等排查信息保留在展开区。

## 属性表核查

`getTypeChart` 按攻击属性读取独立映射。新增测试确认冰和幽灵属性表不同，幽灵表包含对超能力/幽灵的克制和对一般属性的无效关系。尚无证据证明此次真实调用传入了幽灵却返回冰，因此没有根据模型自述修改正确的属性表。
