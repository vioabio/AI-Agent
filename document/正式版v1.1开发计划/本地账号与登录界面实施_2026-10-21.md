# 本地账号与登录界面

## 功能范围

- 登录页沿用绿白工作区风格：宝可梦插图、登录/创建账户切换、密码显示切换、错误提示和恢复入口；支持手机。
- 用户名大小写不敏感，仅允许 3～32 位字母、数字、下划线；密码至少 10 个字符，UTF-8 编码不超过 72 字节。
- 创建账户后显示一次恢复码，确认保存后返回登录；恢复码以 BCrypt 哈希保存。重设密码或修改密码均轮换恢复码与账号凭据版本。
- 工作区左下角账户菜单提供账户设置、切换账号、退出。设置包含昵称、三种预设头像和密码修改；弹窗不卸载工作区，关闭后保留草稿。
- 账号保存在 `.local-data/accounts.sqlite`，聊天在 `history.sqlite`，队伍在 `teams.sqlite`，新增收藏持久化在 `favorites.sqlite`。路径均可配置；默认数据目录已被 Git 忽略。

## 身份与安全

账号使用服务端生成的稳定内部 ID，业务请求由安全过滤链和身份拦截器确定归属，不接受前端伪造用户 ID。普通本机账号固定为 trainer，只获得训练家工具白名单。运营、知识发布、旧 `/ai/**` 兼容接口等入口在本地账号模式下禁止访问，不能通过开发模式角色头提权。

采用 Spring Security 服务端会话，Cookie HttpOnly、SameSite=Lax、仅 Cookie 跟踪；登录轮换会话，空闲 30 分钟或绝对 8 小时到期。写操作校验 CSRF 与来源。登录、恢复、注册和密码修改有持久化冷却计数；重启不能绕过冷却。

修改密码后其他旧版本会话失效，当前浏览器会话也被轮换，以便用户保存新恢复码。用户确认保存后退出并重新登录。恢复密码后所有旧版本会话失效。密码和恢复码不写入浏览器持久存储。

本地账号与 OIDC 互斥。复用现有工具授权策略快照及绑定类型，不将本地密码转为外部 OIDC 凭据，也不向浏览器返回模型 API Key。

## 旧数据认领

首次创建的本机账号可在账户设置中查看匿名旧聊天与旧队伍数量，再输入当前密码并勾选确认后认领。不自动迁移，不支持指定任意来源账号。其他账号不能认领，已有私有资源保持原归属。各 SQLite 文件内事务执行，操作可重复重试；不是跨文件原子事务。

认领范围是已持久化的匿名会话、消息和队伍，不包含已丢失的旧内存收藏、旧 Run 事件或执行租约，不开放跨账号 Run 恢复。

## 使用步骤

1. 重启后端，使新增认证过滤链和接口生效；前端开发服务通过 HMR 更新，必要时刷新网页。
2. 在登录页选择“创建账户”，填写用户名、昵称与密码，保存恢复码，然后登录。
3. 登录后从工作区左下角头像进入“账户设置”，修改资料或认领自己的旧数据。
4. 数据仅在当前电脑保存；重启后需要重新登录，但账号及持久化资源保留。

默认仅 `local & !prod & !demo` 配置启用。可用 `VIO_LOCAL_ACCOUNTS_ENABLED=false` 回到原有开发认证模式；使用企业 OIDC 前必须先关闭本地账号。账号路径可通过 `vio.local-accounts.path` 设置，配置模板另提供 `VIO_LOCAL_ACCOUNTS_PATH` 环境变量。
