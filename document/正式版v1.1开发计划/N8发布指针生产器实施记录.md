# N8 发布指针生产器实施记录

## 范围

本次落地的是 N8 的离线、可审计最小 producer 链：

- `tools/resolve-active-release.mjs`：从显式的本地 registry JSON 快照解析 active pointer。
- `tools/resolve-previous-release.mjs`：从 active/previous pointer 解析唯一生产 GA 上一版本。
- `tools/register-release-pointer.mjs`：根据已 hash 绑定的 manifest 生成 pointer 产物；不执行 registry 写入。
- `tools/verify-release-pointer.mjs`：校验 pointer、manifest、上一版本和 digest 的绑定关系。
- `tools/lib/release-pointer.mjs`：路径、JSON、secret 扫描、hash、时间和原子输出共用逻辑。
- `tools/n8-release-pointers.test.mjs`：合成 fixture 的通过、篡改、What-if、no-clobber 和离线 pending 路径。

## 安全与边界

1. 四个脚本只接受 `--repo-root` 内的显式文件；`--registry` 仅作为脱敏元数据，不能替代 `--registry-file`，不会发起 DNS/HTTP/registry API 请求。
2. 输入 JSON 的原文和解析结果都会做 secret-like 扫描；报告只写路径、SHA-256、release/environment/status 和 reason code，不复制证据正文。
3. manifest hash 必须与目标文件实际 SHA-256 相等；pointer 的 manifest path、releaseId、releaseClass、environment、releaseStatus、backend digest、时间和可选 expiresAt 必须一致。
4. `resolve-previous-release` 不按时间排序猜测上一版本；没有显式 previous pointer 时，仅在快照中存在唯一 GA/prod 记录时继续，否则保持 `blocked`/`environment-pending`。
5. `register-release-pointer` 永不修改 registry。缺少前置条件或使用 `--what-if/--dry-run` 时输出 `status=pending`，`mutation=not-performed`，并返回非 0；真实注册仍需经过外部发布适配器和审批。
6. 所有输出支持 `--no-clobber`，通过临时文件 + fsync + atomic rename 写入。生产观察期、签名验证、真实 registry mutation 和 72 小时证据仍未由本次静态 producer 证明。

## 最小命令示例

以下示例只使用脱敏的本地快照；真实密钥不得写入命令行、JSON 或 artifacts。

```powershell
node tools\resolve-active-release.mjs --repo-root . --registry-file artifacts\v1.1\release\registry-snapshot.json --environment prod --active-pointer --require-environment prod --require-release-class RC,GA --expected-release-id $releaseId --expected-manifest artifacts\v1.1\release\candidate-release-manifest.json --require-status RC,GA --output artifacts\v1.1\prod\active-release-resolution.json --report artifacts\v1.1\prod\active-release-resolution-report.json --no-clobber

node tools\resolve-previous-release.mjs --repo-root . --registry-file artifacts\v1.1\release\registry-snapshot.json --environment prod --active-pointer --require-status GA --require-release-class GA --schema contracts\release-manifest-v1.1.schema.json --candidate artifacts\v1.1\release\candidate-release-manifest.json --output artifacts\v1.1\release\previous-manifest-final.json --report artifacts\v1.1\release\previous-release-resolution-final.json --no-clobber

node tools\register-release-pointer.mjs --repo-root . --registry-file artifacts\v1.1\release\registry-snapshot.json --registry registry.example/vio --environment prod --release-class GA --manifest artifacts\v1.1\release\release-manifest.json --manifest-hash artifacts\v1.1\release\release-manifest.sha256.json --expected-previous artifacts\v1.1\release\previous-manifest-final.json --previous-output artifacts\v1.1\release\active-release-pointer.previous.json --output artifacts\v1.1\release\active-release-pointer.json --report artifacts\v1.1\release\active-release-pointer-register.json --atomic-replace --allow-create --no-clobber

node tools\verify-release-pointer.mjs --repo-root . --pointer artifacts\v1.1\release\active-release-pointer.json --manifest artifacts\v1.1\release\release-manifest.json --environment prod --require-status GA --require-release-class GA --report artifacts\v1.1\release\active-release-pointer-validation.json --no-clobber
```
