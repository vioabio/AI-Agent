# VIO 正式版 v1.1 开发计划

本目录把 v1.0 候选构建推进到可现场验收、可恢复、可运营、可量化、可回滚的 v1.1 GA。文档中的目标、命令和证据路径不是已完成声明；当前真实依赖和发布验收仍以证据为准。

**最新进度（2026-10-09）：** 当前处于 S0 基线修复收尾，主要修复已提交，但 demo profile 激活、数据库 IT/CI 门禁和 JDBC 首次幂等 claim 仍需收敛；S1 的 OAuth2 Client 依赖已开始准备。剩余任务、实测边界和实施顺序见[当前开发进度与剩余开发计划](./当前开发进度与剩余开发计划_2026-10-09.md)。

## v1.1 阶段

```text
N0 基线/真实环境
  → N1a 摄取与候选索引
  → N2 Run 耐久化
  → N3 治理与隐私
  → N4 领域 API/资产
  → N5 前端/E2E
  → N6a 评测/OTel → N1b 原子发布 → N6b 反馈闭环
  → N7 staging/灾备/灰度
  → N8 GA 观察与签收
```

关键规则：v1.0 的 M2～M7 代码骨架不重复搭建；测试数量与当前验证结果见最新进度文档。离线通过不能替代真实 PG/PGVector、外部模型/MCP、Docker、监控、恢复和发布证据。任一 P0 证据缺失，状态保持 `BLOCKED`。

所有证据统一写入 `artifacts/v1.1/`，发布 manifest 通过 `artifactRoot` 解析相对路径；候选 manifest、preflight manifest 和最终 GA manifest 不可原地互相覆盖。
