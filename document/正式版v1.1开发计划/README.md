# VIO 正式版 v1.1 开发计划

本目录把 v1.0 候选构建推进到可现场验收、可恢复、可运营、可量化、可回滚的 v1.1 GA。文档中的目标、命令和证据路径不是已完成声明；当前真实依赖和发布验收仍以证据为准。

**最新进度（2026-10-14）：** 在 R09 租约提交隔离基础上，本轮已完成 R07 步骤输出 artifact 接入：不可变 `RunStepOutput`、内存/JDBC 仓储、V27 迁移、canonical JSON、受控 codec、摘要/密文校验、lease fence 写入和 demo/prod wiring 均已落地。服务级 artifact、仓储和 wiring 定向回归共 24/24 通过；离线后端全量 749 个测试执行通过（2 个环境相关测试跳过，0 失败/错误），证据见 `artifacts/r07-backend-full-2026-10-14.log`。R07 仍明确保持 fail-closed，不能把 artifact 存在当作可恢复授权；授权快照、真实 PostgreSQL/多实例恢复、R09 控制事务、跨实例通知和发布验收仍待完成。详见[R07 步骤输出实施记录](./S3R07步骤输出持久化实施记录_2026-10-14.md)和[S2 租约实施、剩余计划与学习路线](./S2租约提交隔离实施记录_2026-10-12.md)。R06 前端行为 98/98、工具评测 91/91、OpenAPI 兼容结果和 S1 浏览器 28/28 属历史证据，本轮未重跑。Surefire JVM 收尾超时仍是非阻断警告，需在发布前定位。

## v1.1 阶段

```text
N0 基线/真实环境
  → N1a 摄取与候选索引
  → N2 Run 耐久化
  → N3 治理与隐私
  → N4 领域 API/资产
  → N5 前端/E2E
  → N6a 评测/OTel → N1b 原子发布 → N6b 反馈闭环
  → N7 staging/灾备/灰度
  → N8 GA 观察与签收
```

关键规则：v1.0 的 M2～M7 代码骨架不重复搭建；测试数量与当前验证结果见最新进度文档。离线通过不能替代真实 PG/PGVector、外部模型/MCP、Docker、监控、恢复和发布证据。任一 P0 证据缺失，状态保持 `BLOCKED`。

所有证据统一写入 `artifacts/v1.1/`，发布 manifest 通过 `artifactRoot` 解析相对路径；候选 manifest、preflight manifest 和最终 GA manifest 不可原地互相覆盖。
