# VIO 宝可梦智能体 v1.1.0

发布日期为2026-11-17，仓库为 `vioabio/AI-Agent`，Git版本标签为 `v1.1.0`。本次发布由用户明确授权，以合并后的main和本轮修复构建运行包。

## 发布内容

- U1检索精排，包含BM25、Embedding、RRF融合、候选预算、返回校验、降级与来源观测。
- U2五类答案块，覆盖图鉴、伤害、证据、队伍建议与培养计划，支持图鉴联动、草稿载入和用户确认。
- U3六份内置任务Skills、角色工具权限交集、上下文预算及完整工具调用配对。
- U4领域Observation与可选OpenTelemetry/OTLP，覆盖模型、工具、执行与审批相关链路。
- U5三项公开只读STDIO MCP工具、参数治理、取消传播和客户端恢复验证。
- U0/U6题集、首答记录、修复回归、工程验证与打包核对。
- 网页图鉴侧栏高度适配、多结果翻页、来源浮层及键盘操作。
- 完整学习路线与460题面试全书，提供2026-11-17版PDF。

## 本轮体验修复

1. 种族值与实际能力的单一追问采用简短机制说明，明确输出要求优先于详细偏好。
2. 仅比较HP和速度的请求只列四个已核对数值及来源。
3. 道馆建议承接本轮或历史明确声明的朱/紫版本，继续询问缺失的进度与成员条件。
4. 中文名称表未识别与上游不可用分别通过工具边界分类。缺失目标的查询收紧为结果提示，带检索任务的混合问题继续保留来源路径。
5. 零伤害原因追问根据本轮重新计算的证据解释，避免重复完整配置和未请求的下一步建议。
6. 补齐“如果都为2倍，能保证一招结束战斗吗”等条件追问，由确定性路由说明所缺计算条件。

## 运行包与源码身份

运行包命名为 `VIO-v1.1.0-20261117.zip`，同目录提供 `.zip.sha256`。

包内包括可执行 `app.jar`、`frontend-dist`、本地伤害引擎及依赖、`RELEASE.md`、`RUNNING.md`、`SHA256SUMS` 和 `manifest.json`。manifest记录源提交、逐文件大小与SHA-256，Git标签可用于取得对应源码。

产品版本使用Git标签 `v1.1.0`，沿用项目既有Maven制品版本 `0.0.1-SNAPSHOT`。构建使用JBR 25，Java编译目标为21。模型、Embedding、精排、用户数据库与私有运行配置通过本机配置提供。

本地候选 `v1.1.0-rc.1-local` 封存于2026-11-16，历史候选摘要按其manifest阅读。

## 本机复现构建

在包含本次提交的干净工作树执行。构建与包目录使用新的 `artifacts` 子目录。

```powershell
.\mvnw.cmd -B -ntp '-Dvio.build.directory=artifacts/v110-build' package
npm --prefix vio-ai-agent-frontend run build
.\ops\local\package-release.ps1 `
  -BackendJar artifacts/v110-build/vio-ai-agent-0.0.1-SNAPSHOT.jar `
  -OutputDirectory artifacts/releases/VIO-v1.1.0-20261117 `
  -ReleaseVersion v1.1.0
```

通过项目README配置本机凭证并启动。答案块、Skills和上下文装配使用 `local,deepseek,v11-preview`，三角色、Embedding、精排和追踪各自按实际需要开启。

## 发布后的流水线核对

`v1.1.0`标签和运行包绑定源码提交`bd6919fa4409930b04b9642031a98c357f444fe0`，279项文件摘要及ZIP摘要核对通过。运行包健康、登录、运行时诊断和伤害接口通过验证，计算使用已核验的公开参考缓存。空缓存首次查询时，本机直接访问PokéAPI出现503，实际运行需保证上游连通或使用有效缓存。
