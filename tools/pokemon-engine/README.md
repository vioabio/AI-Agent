# 本地伤害桥接

默认入口为 `calculate-v2.cjs`，使用固定的 `@smogon/calc` 0.12.0。v2 在零伤害时直接描述已计算的 0–0，不调用 SDK 的击倒概率描述器；正伤害输出和输入约束保持 v1 契约。它不实现新的伤害公式，也不推导胜率。

`calculate.cjs` 保留为 v1 历史入口，供已冻结的攻略代码引用、旧证据及兼容测试核验。它在某些零伤害数组上会因 SDK 描述器抛错而拒绝请求；新配置应使用 v2。不要通过改写旧题集、历史证据或既有源码摘要使审计静默通过。

在项目根目录执行 `node --test tools/pokemon-engine/calculate.test.cjs`。覆盖真实 SDK、天气、输入拒绝、零伤害，以及 v1/v2 正伤害输出兼容。Node 进程仍仅在本机按请求运行，没有额外网络服务。自定义 `VIO_DAMAGE_SCRIPT` 时需自行确认对应脚本和依赖版本。
