# 工具实际输入开发回归

固定4条案例，各2次，共8次任务：火攻击草、幽灵攻击一般、幽灵攻击属性表，以及明确给定完整攻防配置的伤害计算。计划不修改S2的36条种子题或22条保留集，也不是100题语义评测。

新工具证据以governanceEventId关联同一次调用的开始、重试、缓存和终态；完整参数摘要及工具版本必须一致。属性、数值、有限枚举和显式null可直接核对；自由文本字段保存SHA-256(JSON字符串)，按预期值逐字段比较。缺少字段与显式null分开，数组保留长度及顺序；摘要不是加密或匿名化保证。

```powershell
# 启动对应代码的独立本地实例后，输出目录须尚不存在
node tools/campus/s2-tool-input-scenario.mjs http://127.0.0.1:18144/api artifacts/campus/tool-inputs/my-capture
node tools/campus/tool-input-report.mjs artifacts/campus/tool-inputs/my-capture/capture.json artifacts/campus/tool-inputs/my-analysis
node --test tools/campus/*.test.mjs
```

采集器创建专用本地账号，密码和Cookie只在内存；不提交审批或修改队伍。accounts/history/teams/guides和PokéAPI缓存均使用隔离路径。开始前有一次独立HTTP伤害控制请求，检查依赖并预热公开参考缓存；它不是模型调用，不能作为冷启动或性能实验。

报告验证冻结计划、原始事件和历史摘要、任务完成、回答一致、用量快照及预期工具参数。失败、缺失和不完整证据保留在固定分母中；不使用仅看回答数字的办法推断工具输入正确。对同一个必需工具有多次成功调用时，全部成功调用都须匹配，不用最后一次掩盖之前的错误条件。

本计划要求给定JSON原样传入，故同时核对完整参数摘要；合法别名、大小写变更或等效默认值也可能不满足该严格要求。字段不一致意味着“没有验证预期传入值”，不能单独认定模型的宝可梦知识错误。S2通用采集器仅核对其参考条件中明确给定的字段，不声称验证了未指定的默认值。

默认local Run事件仍受内存保留期限制。成功聊天历史不因此获得跨重启的完整参数审计；本轮证据需要单独保存采集文件。原始文本、未知字段、写工具和通用网络/终端工具不会通过该证据投影额外输出。
