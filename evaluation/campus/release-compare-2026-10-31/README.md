# v8 定向复核与两个新输入

本目录含8题：6个已经观察的回归输入（比较失败原题、v7的4个题、旧显式伤害题），以及v8冻结后固定的2个未参与调试的否定指令变体。原回归题的正文和判据不改，heldout仅为采集器执行标签，不代表8题都是新题。
