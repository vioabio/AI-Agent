校验原始输入出处、冻结题集身份、候选状态及精确重复。报告不输出原保留集问题；精确匹配只提示候选和案例ID，不能代替语义去重。AI改写必须标明 `AI_AUTHORED_VARIANT` 和原候选，不计为独立用户问题。

纳入新正式版本之前，应依次完成：

1. 补充可核对来源和实际输入条件，确认当前版本、赛制及可用工具。
2. 人工核对问题代表性、事实边界与验收条目，登记审核信息。
3. 与既有问题做语义分组和去重；同一任务改写及同一来源相关题不得跨开发/保留切分。
4. 发布独立新题集版本，保留旧版和报告；先冻结题目与切分，再运行评测。
